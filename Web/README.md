# zisla 官网

这是仓库根目录下的 TypeScript 官网，使用 Vite 构建，页面文案和下载入口与仓库当前 macOS Release 保持一致。

## 本地运行

```bash
cd Web
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
