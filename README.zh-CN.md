# zisla

[English](README.md) | **简体中文** | [其他语言](docs/locales/README.md)

**zisla 是一个在需要时出现、平时保持收起的原生 macOS 动态工作空间。** 将鼠标移到屏幕顶部中央，即可在轻量工作台中查看 AI 任务、媒体、文件中转、下载和常用桌面工具；无刘海显示器也会使用同样轮廓的模拟状态条。

当前实现支持 **macOS 14+**。Apple 芯片 Mac 为受支持配置；Intel 机型可能存在可用的发布包，但不保证兼容性。

## 为什么它适合放在屏幕顶部

- **按需出现，不抢焦点。** 从屏幕顶边展开，必要时固定面板，同时继续在当前应用中工作。
- **把正在进行的事放在一起。** 无需打开完整仪表盘，即可查看正在播放、AI 任务、下载、计时器、邮件、系统状态和电池信息。
- **看见 AI 工作，不读取对话。** zisla 仅读取判断任务状态所需的结构化事件和本地活动元数据，绝不读取提示词或回答正文。
- **控制权留在本机。** 功能模块、剪贴板历史和链接检测均可独立开关；权限只在功能首次实际需要时请求。

## 能做什么

### 保持桌面工作流顺畅

| 能力 | 说明 |
| --- | --- |
| 正在播放 | 显示封面、标题、进度、滚动歌词和播放控制；没有媒体元数据时，Core Audio 可识别实际输出音频的应用。 |
| 文件中转与共享 | 将文件、音视频或链接拖到屏幕顶部触发带，放入中转站、在 Finder 中定位，或调用 macOS 系统共享菜单。所选文件和文件夹可压缩为 ZIP，所选图片可带入图片工具缩放或转换并将成功结果返回中转；所选图片、视频和音频可导入录屏素材库，保留当前工程和时间线。 |
| 剪贴板与通知 | 可选记录本机剪贴板历史、仅在本机识别新链接，并在收起状态显示媒体、AI 活动、浏览器下载、计时器、邮件和更新。可选的快捷操作在每次复制后弹出小灵动岛提示，展示富内容预览和智能下一步动作（打开、Finder 定位、搜索、翻译、计算、保存）。浏览器下载完成或收到 AirDrop 文件后，也可用同一快捷键打开文件所在文件夹。新历史图片会加入本机文字识别队列，可按图片内文字找回原图；右键图片可识别或复制文字。 |
| 日常工作区 | 提供天气、日历、提醒事项、Mail.app、以系统「备忘录」为数据源的 Markdown 笔记、锁屏信息和可选桌面宠物。可以预览并固定一只宠物，也可以让 zisla 在本地零点或按自定义间隔，从选定的宠物中随机抽取一只。 天气信息不全时继续查询其他来源，以最完整结果为基础补齐缺项；无法补齐时保留已有可用信息。 |

### 让 AI 工作状态可见

zisla 可监控 Codex、Claude Code、Pi、GitHub Copilot、Gemini、Grok、Kimi Code、Qwen Code、Qoder、ZCode、Zed Agent、Delta、Orca、TRAE、OpenCode、Harnext、WorkBuddy、WorkBuddy AI 等本地活动源，展示任务、状态、token 趋势、贡献热力图和侧边通知。

对于没有稳定本地活动源的工具，可通过 `zislactl` 让脚本、CI 和工具 hook 上报进度、用量与通知，协议状态始终保存在这台 Mac 上。设置中还可检测、安装、更新和卸载常用 AI CLI，并管理本机 Skills。Provider 与命令见 [CLI 接入设计](mac/Docs/cli-reference.zh-CN.md)。

### 处理桌面上的细碎工作

| 范围 | 已包含工具 |
| --- | --- |
| 下载与文档 | 通过 `yt-dlp` 下载视频与音频；在本机完成 PDF 合并、拆分、旋转、裁剪、转换、渲染、文本导出、水印、页码、加密、解除密码和元数据编辑。 |
| 专注与展示 | 番茄钟（每段结束播放一次提示音并显示本机通知）、保持亮屏、防止空闲休眠、屏幕与键盘清洁、提词器和摄像头镜子。计时器名称仅用于当前计时，结束或取消后恢复默认名称。灵动岛收起时，太阳表示保持亮屏，笔记本电脑表示防止空闲休眠。 |
| 系统与电池 | CPU、GPU、内存、磁盘、网络、风扇和电池信息，以及安全可删除的缓存和日志清理。 |
| 语音输入 | 全局快捷键录音与转写、可选本地或远端转写整理，以及本机语音记录。 |

### 当前入口与工作流

岛内有 12 个模块：首页、中转、剪贴板、AI 监控、键盘声音、下载、日程、邮件、随记、应用混音、小工具和系统。电池在系统中查看；锁屏属于独立展示能力。PDF、图片、音频工具从设置进入；录屏工作室从设置或菜单栏进入。

- **录屏与创作：** 录制屏幕、窗口或区域，选择系统音频、麦克风和摄像头；在多轨工作室编辑字幕、缩放、人像与声音效果，预览后导出视频、GIF、Live Photo 或音频。图片工具有 9 项本机操作，音频工具有 27 项操作。
- **混音与播放：** macOS 14.4+ 可逐应用调节音量与静音；媒体区域可选择输出设备，设置可选择播放器偏好。
- **桌面与会议：** Dock 和 Command+Tab 窗口预览、网页/窗口/桌面位置便签、会议开始前 10 分钟倒计时、加入会议及关联便签。拖拽文件时摇动鼠标可显示中转投放入口。
- **每日简报：** 8 种模板，预览、手动或定时 PNG 导出，选择统计内容和独立保存位置。
- **AI 账户：** 查看支持账户的剩余额度、重置时间、低额度通知和采样时间；本机 token 历史可导出 `.xlsx`。 Antigravity 的 Gemini 与 Claude/GPT 额度分别监控、展示和提醒。Gemini App 普通对话额度使用同一 Google 账号的网站 Cookie 查询；Gemini CLI 单独监控。
- **快捷操作：** 弹窗内 `Command+1` 到 `Command+0` 按动作顺序执行；新配置额外默认触发键为 `Command+N`，用于首个动作。已保存组合和清空状态在升级时保留。
- **菜单栏管理** — 逐个显示或隐藏菜单栏图标，所属应用继续运行。

[用户帮助](https://wzz6423.github.io/zisla/help.html?lang=zh-Hans#help)提供剪贴板、截图/录屏、中转、会议、AI、媒体工具、每日简报、桌面便签/窗口预览和播放/混音九组逐步指南。[macOS 指南](mac/README.zh-CN.md#保存位置)列出各工具保存目录与依赖。

## 快速开始

### 安装应用

从 [GitHub Releases](https://github.com/wzz6423/zisla/releases) 或 [Gitee Releases](https://gitee.com/wzz6423/zisla/releases) 下载最新 DMG，挂载后将 `zisla.app` 拖入 `Applications`。

也可以用 Homebrew 安装：

```bash
brew install --cask wzz6423/tap/zisla
```

Homebrew 会按你的芯片选择对应架构的包，Apple Silicon 与 Intel 各自只下载自己那一份。该 cask 来自第三方 tap `wzz6423/tap`，不在 Homebrew 官方 cask 仓库中，安装即意味着信任这个 tap。

启动后，将鼠标移到当前屏幕顶部中央即可展开；也可从菜单栏图标选择“显示灵动岛”。发布包未经公证，因此无论用哪种方式安装，首次打开都需要在“系统设置 > 隐私与安全性”中选择“仍要打开”，或自行清除隔离标记：

```bash
xattr -d com.apple.quarantine /Applications/zisla.app
```

### 更新应用

无论用哪种方式安装，zisla 都通过 Sparkle 自行更新。用 Homebrew 安装的情况需要额外说明：`brew upgrade` 只在已装应用确实旧于 tap 中的版本时才替换它——Homebrew 5.1.6 起会读取应用包内的版本号，因此它既不与 Sparkle 相争，也不会放着落后的安装不管。显式指定 cask 依据的是 Homebrew 自己的安装记录，可能把 Sparkle 更新过的应用退回 tap 的版本：

```bash
brew upgrade --cask zisla
```

tap 只提供正式版，预览包仅发布在 Releases，`brew upgrade` 不会把你带到预发布版本；反过来，正在用预览版时显式指定 cask 会把它替换成当前正式版。Sparkle 自身从不降级，切回 Release 通道后会停在预览版本，直到正式版的构建号超过它。`brew uninstall --cask zisla` 卸载应用，`brew uninstall --zap --cask zisla` 会连同本地数据一起清除。

### 从源码运行

开发环境需要 Swift 6 / Xcode 16+；仅安装 Command Line Tools 也可构建。

```bash
cd mac
swift run zisla
```

下载器需要 `yt-dlp`，`ffmpeg` 为可选依赖；Office 转 PDF 需要 LibreOffice 或 OpenOffice。构建、测试和打包命令见 [macOS 开发指南](mac/README.zh-CN.md)。

## 设计为不打扰工作

- 支持多显示器、Spaces 和普通全屏应用；展开时不会激活或抢走当前应用焦点。
- 连接多显示器时，在「设置 → 通用 → 显示器模式」分别选择灵动岛模式（摄像头或自定义位置）、刘海模式，或在该屏幕不显示。单屏时隐藏此设置，使用原有全局样式；重新连接后恢复各屏幕的配置。启用灵动岛的屏幕会同时显示收起的岛。在一块屏幕上展开灵动岛、打开快捷操作、录音或显示临时提示时，其他屏幕的岛保持可见。选择通知显示器只决定哪块屏幕显示通知。
- 隐藏状态不创建常驻透明热区窗口，也不运行帧循环；通过全局事件监听与几何判断触发展开。
- 使用单层系统材质；系统开启“降低透明度”后自动使用实体背景。
- 物理刘海通过系统安全区域推断；无刘海的外接显示器使用同样轮廓的覆盖层。

具体实现取舍见 [架构与性能设计](mac/Docs/architecture.zh-CN.md)。

## 隐私与权限

zisla 仅在启用的功能首次实际需要时请求系统权限。你可以随时在设置中关闭模块，或在 macOS 系统设置中撤销授权。

| 范围 | 边界 |
| --- | --- |
| AI 活动 | 仅读取结构化事件和本地活动元数据，绝不读取提示词或回答正文。 |
| 剪贴板与文件 | 剪贴板历史、链接检测和快捷操作是独立的本地开关；快捷操作处理已完成的浏览器下载与收到的 AirDrop 文件，不受“浏览器下载进度”开关影响。识别全部在本机完成，仅在用户明确点击或按下触发键后才打开链接或执行动作。文件中转使用安全书签，不复制原始文件。 |
| 备忘录、邮件与语音 | 备忘录和邮件通过 AppleScript/JXA 访问，并要求自动化授权。语音仅在主动使用时录音；整理功能只向选定的本地模型、远端 Provider 或 CLI 档案发送转写文本。 |
| 浏览器下载与媒体 | 使用 macOS 公共文件进度、MediaRemote 元数据和 Core Audio 输出状态，不读取浏览器历史数据库。系统波形和应用混音在本机处理音频；录屏仅在启用对应源时保存声音。 |
| 网络 | 天气、公网 IP 查询、更新镜像选择、下载、启用的 AI 额度检查和依赖/CLI 安装访问对应服务。可选翻译、语音整理与录屏 AI 编辑访问选定 Provider 或 CLI；Apple 语音识别是否联网取决于系统与语言支持。 |

### 按功能授权

首次使用相关功能时，zisla 会请求所需授权。若此前拒绝过，可在「系统设置 > 隐私与安全性」中打开对应项目并允许 `zisla`；macOS 版本不同，项目名称可能略有差异。

| 授权或系统设置项目 | 何时需要 | 授权后的范围 |
| --- | --- | --- |
| 设备控制和数据访问（部分版本显示为「辅助功能」） | 将语音转写自动填入当前应用的输入框 | 读取并定位非密码输入框，通过系统辅助功能接口或 `Cmd+V` 投递转写；未授权时转写仍会复制到剪贴板。 |
| 麦克风 | 语音输入或启用工作室麦克风 | 为录制或已启用的监听采集所选麦克风。 |
| 语音识别 | 将录音转为文字 | 仅处理主动录入的语音。语音输入需要同时允许「麦克风」和「语音识别」。 |
| 完全磁盘访问权限 | Mail.app 未运行时查看邮件 | 读取 `~/Library/Mail` 的本地索引，以显示账户、发件人、主题、摘要、时间和已读状态。此处的 Mail 索引读取路径需要该授权。 |
| 自动化 | 读取、撰写、回复、标记或删除 Mail.app 邮件；读写系统「备忘录」 | 允许 zisla 控制相应的系统应用；邮件操作和随记分别可在系统设置中撤销。 |
| 日历；提醒事项 | 使用日程模块 | 分别读取并管理日历事件和提醒事项。 |
| 定位服务 | 使用当前位置天气 | 仅获取一次当前位置，不持续跟踪；手动添加的地点不需要定位权限。 |
| 摄像头 | 打开镜子或启用工作室摄像头预览/录制 | 仅在对应功能运行时使用所选摄像头。 |
| 输入监控 | 键盘声音、按键统计、键盘清洁与修饰键/鼠标侧键快捷键 | 按启用功能监听事件；按键统计保存在本机。 |
| 蓝牙 | 在系统 → 电池中查看配件电量 | 仅读取已连接或已配对设备公开的电量信息。 |
| 录屏与系统录音（旧版 macOS 可能显示为「屏幕录制」） | 截图、窗口预览、录屏、系统音频波形与应用混音 | 读取屏幕图像和所选音频源；录屏在本机保存启用的源，混音需要 macOS 14.4+。 |
| 通知 | 使用番茄钟提醒 | 在计时结束时播放一次提示音并显示本机通知。 |
| 用户选择的文件夹（无需手动授权） | 文件中转、导入导出或选择下载目录 | 通过系统文件选择器取得你选定目录的访问权，不需要为这些功能授予完全磁盘访问权限。 |

撤销任一授权只会停用对应功能，不影响其他模块。若在系统设置中刚刚修改开关但功能仍不可用，退出并重新打开 zisla 后再试。

完整的权限与网络行为见 [macOS 开发指南](mac/README.zh-CN.md#权限和隐私)。
