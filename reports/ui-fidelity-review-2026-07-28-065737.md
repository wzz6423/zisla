# 首页 UI 排查报告

> 生成时间: 2026-07-28 06:57
> 评审工具: ui-checker
> 设计依据: 用户提供的首页截图与运行中 `zisla` 窗口

**结论**: 已修复首页高度与实际卡片渲染不同步造成的空黑区域。

## 发现

- 运行中的首页窗口为 `904 x 209`，其中 44pt 为宠物侧栏；209pt 对应“媒体头 + 工具栏 + 1 张卡片”的布局高度。
- 截图中首页没有动态卡片，导致工具栏下方留下黑色空区。
- `AppModel` 的预估卡片数和 `IslandDashboardView` 的实际渲染条件在状态快速变化时可能短暂不同步。

## 修复

- 首页视图在初次显示及动态卡片数变化时，将实际卡片数同步给 `AppModel`。
- 模型仅在数量变化时发布布局状态，避免不必要的窗口刷新。
- 未修改媒体头、工具栏、卡片样式或交互。

## 验证

- `swift build --package-path mac --target Zisla`：成功。
- `swift test --package-path mac --filter IslandSurfaceTransformTests`：5/5 通过。

## 残余风险

- 当前运行中的 `mac/dist/zisla.app` 是已启动的旧进程；需要重新启动使用新构建的应用后，才能在桌面上观察到修复效果。
