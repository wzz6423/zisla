# UI 问题排查报告

生成时间：2026-07-28 06:58（Asia/Shanghai）

## 结论

常驻宠物窗口在没有紧凑状态内容时，仍使用为 AI、媒体和专注状态预留两侧空间的紧凑状态栏帧。宠物视图正确贴在该窗口边缘，但窗口本身过宽，因此与物理刘海之间出现不必要的空白。

## 修复

- 无紧凑状态内容时，持久宠物窗口回退到物理刘海帧；宠物槽只在刘海两侧各保留既有 4pt 外边距。
- 有紧凑状态内容时，继续沿用原有的状态栏宽度与媒体/专注扩展规则。
