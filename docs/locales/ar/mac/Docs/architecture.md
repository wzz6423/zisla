# تصميم المعمارية والأداء

[English](../../../../../mac/Docs/architecture.md) | [简体中文](../../../../../mac/Docs/architecture.zh-CN.md) | **العربية** | [اللغات الأخرى](../../../README.md)

## التفعيل عند الحافة العليا

لا توجد نافذة شفافة في الحالة المخفية. تثبت `PointerEdgeMonitor` مراقبات `NSEvent` عامة ومحلية لحركة الفأرة والسحب؛ تحدد `ScreenLayoutEngine` بالهندسة وحدها دخول المؤشر منطقة 6 px في منتصف أعلى كل شاشة.

لكل شاشة هوية ثابتة بربط `NSScreenNumber` بـ`CGDirectDisplayID`. يرتكز التخطيط على `screen.frame.maxY`، فيدعم الإحداثيات السالبة والشاشات المكدسة عموديًا والخارجية دون نتوء.

عند توصيل عدة شاشات، تتيح الإعدادات → عام → أوضاع الشاشات اختيار وضع Dynamic Island (موضع الكاميرا أو موضع مخصص) أو وضع النتوء أو الإخفاء لكل شاشة. عند استخدام شاشة واحدة يختفي هذا الإعداد ويُطبّق المظهر العام؛ وعند إعادة التوصيل تُستعاد إعدادات كل شاشة المحفوظة. تظل الجزيرة المطوية ظاهرة على جميع الشاشات المفعّلة في الوقت نفسه. التوسيع والإجراءات السريعة والتسجيل والرسائل المؤقتة تستبدل الجزيرة على شاشتها فقط؛ ويقتصر اختيار شاشات الإشعارات على تصفية المحتوى دون إخفاء الجزيرة الخاملة.

## النافذة

تحتفظ الجزيرة الأساسية بلوحة واحدة `.borderless + .nonactivatingPanel`:

- تستخدم مستوى `.statusBar` ولا تغطي شاشة القفل أو قائمة النظام.
- تدعم `.canJoinAllSpaces + .fullScreenAuxiliary` مساحات Spaces والتطبيقات العادية بملء الشاشة.
- التوسيع بالمرور لا يستدعي `NSApp.activate`، فلا يسحب تركيز التطبيق الحالي.
- تستخدم الحالة المخفية `orderOut`، فلا تشغل نافذة شفافة منطقة القائمة.

تُنشأ لوحتا الإشعارات اليمنى واليسرى عند الطلب وتُخفَيان فور فراغ طوابيرهما.

## الحالة والتزامن

- يبقى AppKit وحالة SwiftUI والتحكم بالنوافذ على `MainActor`.
- عند تفعيل إدارة شريط القوائم، ينشئ zisla عنصري تحكم من نوع `NSStatusItem`. وعندما تكون قائمة الأيقونات مفتوحة، يقرأ `AXExtrasMenuBar` ويتحقق من موضع الأيقونة المحددة بعد نقلها.
- تستخدم التنزيلات والطقس وطلبات GitHub عناصر actor.
- تُراقب حالة AI المكتوبة بالخطافات عبر أحداث نظام ملفات المجلد. يقارن كل مصدر ملف الجلسة أو النشاط المحلي الأحدث بوقت التعديل والحجم ويعيد استخدام ذاكرة التحليل عند عدم التغير.
- يقرأ الاكتشاف التلقائي الأحداث المنظمة وعلامات الحالة الثابتة وبيانات النشاط اللازمة فقط، ولا يقرأ نصوص الطلبات والإجابات. فشل محلل مزود لا يمنع المزودين الآخرين.
- تُؤخذ حصص حسابات AI من كل مزوّد بصورة مستقلة. تحتفظ حصص Gemini وClaude/GPT في Antigravity بفترات إعادة تعيين وتنبيهات مستقلة. تستخدم حصة المحادثات العادية في Gemini App ملف Cookie المحفوظ من الويب لحساب Google نفسه؛ وتحتفظ Gemini CLI بمصدر OAuth المحلي. لا تُقدّر الحصص المفقودة.
- تستخدم تأخيرات الطي مهام `Task` قابلة للإلغاء ورمز جيل، فلا تستطيع مهمة قديمة إخفاء جزيرة أعيد فتحها.
- لا توجد `TimelineView` أو مؤقت 60 Hz أو إرسال تحريك مستمر في الحالة المخفية.

## اكتشاف الوسائط

توفر MediaRemote العنوان والغلاف والتقدم والتحكم. تؤكد خصائص كائنات العمليات في Core Audio 14.4+ وجود تدفق خرج نشط، وتحدد تطبيق المصدر البديل عند غياب البيانات الوصفية. تدير مستمعات الخصائص قوائم العمليات وحالة الخرج مع تحقق دوري محدود؛ لا يُلتقط محتوى الصوت ولا يُطلب إذن تسجيل الشاشة أو Accessibility. لا تبقى المصادر المتوقفة مؤقتًا أو نهائيًا أو المكتومة في منطقة الوسائط.

## التسجيل ومزج التطبيقات

تسجيل الشاشة ومزج صوت التطبيقات منفصلان عن اكتشاف البيانات الوصفية. يطلب التسجيل إذن الشاشة وأذونات الميكروفون والكاميرا المفعّلين، ويحفظ الوسائط المختارة محليًا ويدير المشاريع في مجلد التسجيل المحدد. يستخدم المزج taps Core Audio على macOS 14.4+ ويحتاج إذن تسجيل صوت النظام.

## المواد المرئية

يستخدم macOS 26 طبقة SwiftUI `glassEffect` واحدة، وmacOS 14/15 طبقة `NSVisualEffectView` واحدة. يحول Reduce Transparency الخلفية إلى معتمة. لا تكدس الجزيرة طبقات تمويه أو مواد متعددة.

## حدود أمان التنزيل

يشغل Swift `yt-dlp` باستخدام `Process.executableURL` ومصفوفة معاملات؛ يكون URL دائمًا قيمة argv مستقلة بعد `--`. تُعطل إعدادات التشغيل والإضافات وexec، وتُفرغ قنوات الخرج بالتزامن، ويُحلل التقدم بعلامة JSON خاصة.

تنجح المهمة فقط عند رمز خروج 0 ووجود مسار الخرج وبقاء المسار المحلول داخل المجلد المصرح. تنظف كل مهمة مجلدها المؤقت المسمى UUID وحده.

## فحوص التحديث وتنزيلاته

تحدد القناة المختارة بلد الخروج العام مرة في التشغيل، ثم يستخدم Sparkle appcast الموقع المناسب للبناء المثبت، وينزّل ZIP المشار إليه عبر HTTPS، ويتحقق من توقيعي EdDSA للأرشيف والخلاصة قبل الاستخراج، ويستبدل التطبيق ويعيد تشغيله. يبدأ `CN` بـGitee: `update-release` لـRelease و`preview` لـPreview، ثم يحاول خلاصة GitHub المطابقة مرة؛ البلدان الأخرى تبدأ GitHub وتحاول Gitee مرة. تعذر الاستعلام يبقي Gitee أولًا، وتشير كل خلاصة إلى ZIP موقع على مضيفها. ينشر الإصدار appcast لكل معمارية بجوار `appcast.xml` المشترك؛ تطلب النسخة أحادية المعمارية شريحتها، وتطلب شريحة x86_64 المترجمة `arm64`، فلا تُستبدل بالبناء الشامل. تعد النسخة الشاملة شرائح ملفها التنفيذي وتبقى على `appcast.xml` الذي يخدم أيضًا الإصدارات السابقة للفصل المعماري. يؤثر تبديل الإعداد في الفحص الآلي واليدوي ويعيد دورة Sparkle التالية. لا يحتوي المفتاح العام المضمّن بيانات حساب؛ يبقى المفتاح الخاص في macOS Keychain لمسؤول الإصدار أو ملف خاص مؤمّن منفصل.
