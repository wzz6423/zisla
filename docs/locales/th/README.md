# zisla

[English](../../../README.md) | [简体中文](../../../README.zh-CN.md) | **ไทย** | [ภาษาอื่น](../README.md)

**zisla คือพื้นที่ทำงาน macOS แบบเนทีฟที่ปรากฏเมื่อจำเป็น แล้วหลีกทางให้คุณทำงานต่อ** เลื่อนตัวชี้ไปตรงกลางขอบบนของหน้าจอเพื่อเปิดพื้นที่ขนาดเล็กสำหรับงาน AI ที่กำลังทำ สื่อ การส่งต่อไฟล์ ดาวน์โหลด และเครื่องมือเดสก์ท็อป จอที่ไม่มีรอยบากใช้พื้นที่สถานะจำลองรูปทรงเดียวกัน

ระบบปัจจุบัน: **macOS 14+** รองรับ Apple Silicon; แพ็กเกจ Intel อาจทำงานได้ แต่ไม่รับประกันความเข้ากันได้

## เหตุผลที่เหมาะกับขอบบนของหน้าจอ

- **เปิดตามต้องการโดยไม่แย่งโฟกัส** ขยายจากขอบบน ปักไว้เมื่อจำเป็น และทำงานในแอปปัจจุบันต่อ
- **รวมงานที่กำลังทำไว้ในที่เดียว** ดูสื่อที่เล่น งาน AI ดาวน์โหลด ตัวจับเวลา จดหมาย สถานะระบบ และแบตเตอรี่โดยไม่เปิดแดชบอร์ดเต็มรูปแบบ
- **เห็นกิจกรรม AI โดยไม่อ่านบทสนทนา** zisla อ่านเฉพาะเหตุการณ์ที่มีโครงสร้างและเมทาดาทากิจกรรมในเครื่องที่ใช้ระบุสถานะงาน ไม่อ่านพรอมป์ต์หรือเนื้อหาคำตอบ
- **ควบคุมในเครื่อง** โมดูล ประวัติคลิปบอร์ด และการตรวจลิงก์เปิดปิดแยกกัน ขอสิทธิ์เมื่อใช้ฟีเจอร์เป็นครั้งแรก

### แสดงสถานะงาน AI

zisla ตรวจดูกิจกรรมในเครื่องจาก Codex, Claude Code, Pi, GitHub Copilot, Gemini, Grok, Kimi Code, Qwen Code, Qoder, ZCode, Zed Agent, Delta, Orca, TRAE, OpenCode, Harnext, WorkBuddy, WorkBuddy AI และแหล่งที่รองรับอื่น แสดงงาน สถานะ แนวโน้มโทเคน ฮีตแมปการทำงาน และแจ้งเตือนด้านข้าง

เครื่องมือที่ไม่มีแหล่งกิจกรรมในเครื่องคงที่ใช้ `zislactl` ให้สคริปต์ CI และ hook ส่งความคืบหน้า การใช้งาน และแจ้งเตือน โดยสถานะโปรโตคอลอยู่บน Mac นี้ การตั้งค่าตรวจพบ ติดตั้ง อัปเดต ลบ CLI AI ทั่วไป และจัดการ Skills ในเครื่องได้ ดูผู้ให้บริการและคำสั่งใน [คู่มืออ้างอิง CLI](mac/Docs/cli-reference.md)

### ทางเข้าและขั้นตอนปัจจุบัน

เกาะมี 12 โมดูล: หน้าแรก ส่งต่อ คลิปบอร์ด ตรวจดู AI เสียงแป้นพิมพ์ ดาวน์โหลด กำหนดการ จดหมาย โน้ต มิกเซอร์เสียงแอป เครื่องมือ และระบบ แบตเตอรี่อยู่ในระบบ ส่วนหน้าจอล็อกแยกต่างหาก เปิด PDF/ภาพ/เสียงจากการตั้งค่า และสตูดิโอบันทึกจากการตั้งค่าหรือแถบเมนู

- **บันทึกและสร้าง:** บันทึกจอ หน้าต่าง หรือพื้นที่ พร้อมเสียงระบบ ไมโครโฟน และกล้องตามเลือก แก้คำบรรยาย ซูม เอฟเฟกต์บุคคลและเสียงข้ามแทร็ก ดูตัวอย่าง แล้วส่งออกวิดีโอ GIF Live Photo หรือเสียง เครื่องมือภาพมี 9 งานในเครื่อง เสียงมี 27 งาน
- **มิกซ์และเล่น:** macOS 14.4+ ปรับเสียง/ปิดเสียงแต่ละแอปได้ เลือกเอาต์พุตที่ส่วนสื่อ และค่าผู้เล่นในการตั้งค่า
- **เดสก์ท็อปและประชุม:** ตัวอย่างหน้าต่าง Dock/Command+Tab โน้ตตามบริบทเว็บ/หน้าต่าง/เดสก์ท็อป นับถอยหลัง 10 นาที เข้าประชุมและเชื่อมโน้ต เขย่าตัวชี้ระหว่างลากไฟล์เพื่อแสดงจุดวางบนชั้น
- **สรุปรายวัน:** 8 แม่แบบ ตัวอย่าง ส่งออก PNG เองหรือตามเวลา เลือกตัวชี้วัดและโฟลเดอร์แยก
- **บัญชี AI:** ดูโควตา เวลารีเซ็ต แจ้งเตือนโควตาต่ำ และเวลาตรวจ; ส่งออกประวัติโทเคนในเครื่องเป็น `.xlsx` โควตา Gemini และ Claude/GPT ของ Antigravity แยกการติดตาม การแสดง และการแจ้งเตือน โควตาแชตปกติของ Gemini App ใช้ Cookie เว็บของบัญชี Google เดียวกัน ส่วน Gemini CLI ติดตามแยกกัน
- **การทำงานด่วน:** ปุ่มในป๊อปอัปเรียง `Command+1` ถึง `Command+0` ปุ่มกระตุ้นเพิ่มเติมเริ่มต้นของการตั้งค่าใหม่คือ `Command+N` สำหรับงานแรก อัปเกรดเก็บปุ่มที่บันทึกและการล้างปุ่มไว้
- **จัดการแถบเมนู** — แสดงหรือซ่อนไอคอนแถบเมนูทีละรายการได้โดยที่แอปยังทำงานอยู่

[ความช่วยเหลือผู้ใช้](https://wzz6423.github.io/zisla/help.html?lang=th#help) มีขั้นตอนคลิปบอร์ด จับภาพ ชั้นวาง ประชุม AI เครื่องมือสื่อ สรุปรายวัน โน้ตเดสก์ท็อป/ตัวอย่างหน้าต่าง และเล่น/มิกซ์ [คู่มือ macOS](mac/README.md) ระบุโฟลเดอร์บันทึกและสิ่งที่ต้องติดตั้ง

## เริ่มใช้งาน

### ติดตั้งแอป

ดาวน์โหลด DMG ล่าสุดจาก [GitHub Releases](https://github.com/wzz6423/zisla/releases) หรือ [Gitee Releases](https://gitee.com/wzz6423/zisla/releases) เมานต์แล้วลาก `zisla.app` ไป `Applications`

ติดตั้งด้วย Homebrew ได้เช่นกัน:

```bash
brew install --cask wzz6423/tap/zisla
```

Homebrew ดึงรุ่นตรงชิป จึงดาวน์โหลดเฉพาะส่วน Apple Silicon หรือ Intel ของเครื่อง cask มาจาก tap ภายนอก `wzz6423/tap` ไม่ใช่คลัง cask ของ Homebrew; การติดตั้งหมายถึงเชื่อถือ tap นี้

เปิดแอปแล้วเลื่อนตัวชี้ตรงกลางบนจอหรือเลือก **Show Island** ที่แถบเมนู แพ็กเกจยังไม่ผ่าน notarization; ครั้งแรกไม่ว่าจะติดตั้งอย่างไรต้องใช้ **Open Anyway** ใน **System Settings > Privacy & Security** หรือลบ quarantine เอง:

```bash
xattr -d com.apple.quarantine /Applications/zisla.app
```

### อัปเดตแอป

zisla อัปเดตผ่าน Sparkle ทุกวิธีติดตั้ง สำหรับ Homebrew คำสั่ง `brew upgrade` แทนที่เมื่อแอปเก่ากว่า tap จริงเท่านั้น เพราะ Homebrew 5.1.6 ขึ้นไปอ่านเวอร์ชันใน bundle จึงไม่ขัด Sparkle และไม่เหลือแอปเก่า การระบุ cask ใช้ประวัติติดตั้ง Homebrew และอาจเปลี่ยนแอปที่ Sparkle อัปเดตกลับรุ่น tap:

```bash
brew upgrade --cask zisla
```

tap มีรุ่นเสถียรเท่านั้น รุ่น Preview อยู่ใน Releases จึง `brew upgrade` ไม่เปลี่ยนเป็นก่อนเผยแพร่ แต่ระบุ cask ขณะใช้ Preview จะลงเสถียรปัจจุบันทับ Sparkle ไม่ลดเวอร์ชัน การกลับ Release จึงใช้ Preview ต่อจนเสถียรใหม่กว่า `brew uninstall --cask zisla` ลบแอป และ `brew uninstall --zap --cask zisla` ลบข้อมูลในเครื่องด้วย

### รันจากซอร์ส

ต้องใช้ Swift 6 / Xcode 16+; Command Line Tools อย่างเดียวก็สร้างได้

```bash
cd mac
swift run zisla
```

ตัวดาวน์โหลดต้องมี `yt-dlp`; `ffmpeg` เลือกติดตั้ง การแปลง Office เป็น PDF ต้อง LibreOffice หรือ OpenOffice ดูสร้าง ทดสอบ และแพ็กใน [คู่มือพัฒนา macOS](mac/README.md)

## ออกแบบให้ไม่รบกวน

- รองรับหลายจอ Spaces และแอปเต็มจอทั่วไปโดยไม่ดึงโฟกัสหรือเรียกแอปมาด้านหน้า
- เมื่อเชื่อมต่อหลายจอ การตั้งค่า → ทั่วไป → โหมดจอภาพ ให้เลือกโหมด Dynamic Island (ตำแหน่งกล้องหรือกำหนดเอง) โหมดรอยบาก หรือซ่อนแยกแต่ละจอได้ เมื่อมีจอเดียวจะซ่อนการตั้งค่านี้และใช้รูปแบบส่วนกลาง เมื่อเชื่อมต่ออีกครั้งจะคืนค่าการตั้งค่าที่บันทึกไว้ของแต่ละจอ ทุกจอที่เปิดให้แสดงเกาะจะแสดงเกาะแบบย่อพร้อมกัน การขยายเกาะ การดำเนินการด่วน การบันทึก และข้อความชั่วคราวจะแทนที่เกาะเฉพาะบนจอนั้น การเลือกจอสำหรับการแจ้งเตือนจะกรองเฉพาะเนื้อหา โดยไม่ซ่อนเกาะที่ไม่มีงานทำ
- เมื่อซ่อนไม่มีหน้าต่างโปร่งใสรับเมาส์ถาวรและไม่มีวงจรเฟรม; เหตุการณ์ทั่วระบบกับการตรวจรูปทรงเรียกการขยาย
- ใช้วัสดุระบบชั้นเดียวและเปลี่ยนทึบเมื่อเปิด Reduce Transparency
- ใช้ safe area ตรวจรอยบากจริง; จอภายนอกไม่มีรอยบากใช้ชั้นซ้อนรูปเดียวกัน

ดูข้อแลกเปลี่ยนใน [สถาปัตยกรรมและประสิทธิภาพ](mac/Docs/architecture.md)

## ความเป็นส่วนตัวและสิทธิ์

ขอสิทธิ์เมื่อฟีเจอร์ที่เปิดต้องใช้ครั้งแรก ปิดโมดูลในการตั้งค่าและถอนสิทธิ์ใน macOS ได้ทุกเมื่อ

| ขอบเขต | ข้อจำกัด |
| --- | --- |
| AI | อ่านเหตุการณ์มีโครงสร้างและเมทาดาทาในเครื่อง ไม่อ่านพรอมป์ต์/คำตอบ |
| คลิปบอร์ดและไฟล์ | ประวัติ ลิงก์ และงานด่วนแยกสวิตช์; งานด่วนรับดาวน์โหลดเสร็จ/AirDrop แยกจากความคืบหน้าเบราว์เซอร์ ตรวจในเครื่องทั้งหมด เปิดลิงก์/ทำงานเมื่อคลิกหรือกดจริงเท่านั้น การส่งต่อใช้ security-scoped bookmarks ไม่คัดลอกต้นฉบับ |
| โน้ต จดหมาย เสียง | AppleScript/JXA ด้วยสิทธิ์อัตโนมัติ เสียงบันทึกเฉพาะใช้งาน; จัดข้อความส่งเฉพาะโมเดล ผู้ให้บริการ หรือ CLI ที่เลือก |
| ดาวน์โหลดและสื่อ | ข้อมูลไฟล์สาธารณะ macOS, MediaRemote และ Core Audio ไม่อ่านประวัติเบราว์เซอร์ รูปคลื่น/มิกซ์ประมวลผลเสียงในเครื่อง บันทึกเฉพาะแหล่งเปิด |
| เครือข่าย | อากาศ IP สาธารณะ กระจกอัปเดต ดาวน์โหลด โควตา AI ที่เปิด และติดตั้งส่วนพึ่งพา/CLI ติดต่อบริการ การแปล จัดเสียง และแก้บันทึก AI ใช้ผู้ให้บริการ/CLI ที่เลือก Apple speech อาจใช้เครือข่ายตามระบบ/ภาษา |

### สิทธิ์ตามฟีเจอร์

ครั้งแรกขอสิทธิ์ที่จำเป็น หากเคยปฏิเสธ ให้เปิดรายการใน **System Settings > Privacy & Security** แล้วอนุญาต `zisla`; ชื่ออาจต่างกันตามเวอร์ชัน

| สิทธิ์/การตั้งค่า | ใช้เมื่อ | การเข้าถึง |
| --- | --- | --- |
| ควบคุมอุปกรณ์และข้อมูล (บางรุ่น Accessibility) | ใส่ข้อความเสียงลงช่องแอปปัจจุบัน | อ่าน/หาช่องไม่ใช่รหัสผ่านแล้วส่งผ่าน Accessibility หรือ `Cmd+V`; ไม่มีสิทธิ์ยังคัดลอกได้ |
| ไมโครโฟน | ป้อนเสียง/ไมค์สตูดิโอ | ไมค์ที่เลือกสำหรับบันทึกหรือฟังที่เปิด |
| รู้จำเสียง | แปลงเสียงเป็นข้อความ | เฉพาะเสียงที่บันทึกขณะใช้งาน; ป้อนเสียงต้องทั้งไมค์และ speech |
| Full Disk Access | ดูจดหมายเมื่อ Mail.app ไม่รัน | อ่าน `~/Library/Mail` เพื่อบัญชี ผู้ส่ง เรื่อง สรุป เวลา และอ่านแล้ว; เส้นทางดัชนีนี้ต้องอนุญาต |
| Automation | อ่าน เขียน ตอบ ทำเครื่องหมาย ลบ Mail.app; อ่าน/เขียน Apple Notes | ควบคุมแอประบบที่เกี่ยวข้อง ถอนแยกกันได้ |
| ปฏิทิน; เตือนความจำ | โมดูลกำหนดการ | อ่าน/จัดการด้วยสิทธิ์แยก |
| ตำแหน่ง | อากาศตำแหน่งปัจจุบัน | ขอครั้งเดียวไม่ติดตาม; ที่เพิ่มเองไม่ต้อง |
| กล้อง | กระจก/ดูหรือบันทึกกล้องสตูดิโอ | กล้องที่เลือกเฉพาะฟีเจอร์ทำงาน |
| Input Monitoring | เสียง สถิติ ล้างแป้นพิมพ์ ปุ่ม modifier เดี่ยว/ปุ่มเมาส์ข้าง | เหตุการณ์ของฟีเจอร์และสถิติในเครื่อง; ปุ่มลัดทั่วไปไม่ต้อง |
| Bluetooth | แบตเตอรี่อุปกรณ์ใน ระบบ → แบตเตอรี่ | ข้อมูลสาธารณะของอุปกรณ์เชื่อม/จับคู่เท่านั้น |
| บันทึกหน้าจอและเสียงระบบ (รุ่นเก่า Screen Recording) | ภาพ ตัวอย่าง บันทึก รูปคลื่น มิกเซอร์ | ภาพและเสียงเลือก บันทึกแหล่งเปิดในเครื่อง; มิกซ์ต้อง macOS 14.4+ |
| แจ้งเตือน | Pomodoro | เสียงหนึ่งครั้งและแจ้งเตือนเมื่อจบ |
| โฟลเดอร์ผู้ใช้เลือก (ไม่อนุญาตเอง) | ส่งต่อ นำเข้า ส่งออก ดาวน์โหลด | ตัวเลือกไฟล์ระบบอนุญาตโฟลเดอร์ ไม่ต้อง Full Disk Access |

ถอนสิทธิ์ปิดเฉพาะฟีเจอร์นั้น หากยังใช้ไม่ได้หลังเปลี่ยน ให้ปิดแล้วเปิด zisla และลองใหม่

[คู่มือ macOS](mac/README.md) ระบุสิทธิ์และเครือข่ายทั้งหมด
