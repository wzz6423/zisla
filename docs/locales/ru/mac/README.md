# zisla для macOS

[English](../../../../mac/README.md) | [简体中文](../../../../mac/README.zh-CN.md) | **Русский** | [Другие языки](../../README.md)

Этот каталог содержит реализацию zisla для macOS. Переместите указатель в центр верхнего края экрана, чтобы развернуть остров; отведите его, чтобы скрыть. Приложение использует AppKit `NSPanel`, SwiftUI и событийные сервисы без постоянного прозрачного окна области активации и без цикла кадров в скрытом состоянии.

Цели Swift, идентификатор пакета, каталог локальных данных и `zislactl` используют идентификатор zisla. Обновления автоматически переносят локальные данные и настройки предыдущих версий.

Поддерживается macOS 14 и новее. macOS 26 использует Liquid Glass; macOS 14/15 — нативный системный материал.

По умолчанию режим «Случайная смена» выбирает из всех питомцев в полночь по местному времени. Ограничьте список в разделе «Питомцы для выбора». - **Лимиты AI и сброс:** Мониторинг AI и Настройки показывают поддерживаемые лимиты, время выборки и сброса, предупреждения малого остатка, включая доступные окна 5h/7d и бюджеты Cursor в USD. Это отдельные данные от локальной истории токенов. Квоты Gemini и Claude/GPT в Antigravity имеют отдельные настройки контроля, отображения и уведомлений. Квоты чата Gemini App используют веб-Cookie того же аккаунта Google; Gemini CLI отслеживается отдельно.

### Порядок клавиш Быстрых действий

Всплывающая панель присваивает `Command+1`–`Command+9`, затем `Command+0` согласно текущему порядку действий. Дополнительный стандартный триггер новых конфигураций — `Command+N`, запускающий первое действие; `Command+Delete` закрывает панель. Триггер, боковая кнопка мыши и порядок настраиваются в Настройках. Обновления сохраняют все явно записанные сочетания, включая старое `Command+1`, собственные клавиши и очищенные триггеры; `Command+N` применяется только к новой конфигурации или отсутствующему полю триггера.

### Управление строкой меню

В разделе «Настройки → Другое → Управление строкой меню» включите разделитель. Удерживая ⌘, перетащите значки на сторону разделителя, противоположную часам. Нажмите стрелку, чтобы скрыть или показать их. С разрешением на универсальный доступ значки можно выбирать по одному прямо на этой странице.

Перемещаемые значки можно сворачивать, даже если в приложении нет настройки для их скрытия. Положение часов и Пункта управления задаёт macOS. В macOS 27 при подключении дисплеев разной ширины некоторые значки могут остаться видимыми на более широком экране.

### Папки сохранения

Настройки → Папка сохранения задают отдельные каталоги загрузок, скриншотов, изображений, записей, PDF, Быстрых действий и ежедневных сводок. Новые конфигурации используют подпапки `~/Downloads`: `picture` для скриншотов/изображений, `video` для записей, `pdf`, `quick` и `daily`. Аудиоинструменты выбирают файл или папку в диалоге экспорта. Файлы полки сохраняют ссылки на оригиналы; сохранённые скриншоты и состояние контекстных заметок хранятся локально в `~/Library/Application Support/zisla`, проекты записи — в папке записей. Текст быстрых заметок находится в Apple Notes.

[Помощь и пошаговые руководства](https://wzz6423.github.io/zisla/help.html?lang=ru#help) охватывают буфер, захват, полку, встречи, AI, медиаинструменты, ежедневные сводки, настольные заметки/предпросмотр окон и воспроизведение/микширование с короткими фрагментами фильма.

### Сочетания и сохранение скриншотов

Действие **Stash** на панели скриншотов находится между **Pin** и **Copy**. Оно сохраняет итоговое отредактированное изображение, включая аннотации и завершённые прокручиваемые снимки, в лотке передачи без копирования в буфер. PNG и метаданные захвата, включая исходное приложение и время, хранятся локально в SQLite и сохраняются после перезапуска. Категория **Stashed screenshots** показывает только эти карточки.

**Highlighter** следует за **Brush** и рисует полупрозрачное выделение; линии концов и круглые маркеры изначально включены и отключаются в меню. **Extract** следует за **Blur** и извлекает объект или фон средствами macOS либо произвольные области свободным выделением. Несколько контуров объединяют сохраняемые области; есть Select All и Clear. Не выбранные пиксели становятся прозрачными, извлечение можно отменить. Радиус углов скриншота изначально равен 0. Перетащите ручку радиуса над выделением или используйте **Corner radius**; значок размера показывает `r`. PNG экспортирует прозрачные углы; возврат радиуса к 0 восстанавливает исходные пиксели углов.

Настройки скриншотов показывают и записывают глобальные и редакторские сочетания. Копирование, сохранение, отмена и повтор отображаются, но не перезаписываются. Пользовательские сочетания сохраняются при обновлении; закрепление является действием редактора, а не отдельным глобальным сочетанием, хотя пункт меню остаётся.

Стандартные сочетания редактора следуют порядку панели: `Control+1`–`Control+9`, затем `Control+0`, `Control+A`, `Control+B` и последующие буквы. Распределение пропускает `Q`, `M`, `N`, `W`: ошибочное нажатие Command могло бы завершить приложение, свернуть, открыть или закрыть окно. Пользовательские сочетания с ними допустимы.

При обновлении нетронутые старые схемы, включая предыдущую Pin/Stash, однократно переходят на эти настройки. Если хотя бы одно сочетание изменено, схема сохраняется; новое действие при конфликте выбирает свободную Control-комбинацию в том же безопасном порядке. Начальные комбинации также можно перезаписать.

## Быстрый старт

### Среда

- macOS 14+
- Swift 6 / Xcode 16+ (сборка возможна с одними Command Line Tools)
- Необязательно: `yt-dlp` и `ffmpeg`; Office в PDF требует также LibreOffice или OpenOffice

С Homebrew:

```bash
brew install yt-dlp ffmpeg
brew install --cask libreoffice
```

### Запуск из исходного кода

```bash
swift run zisla
```

Приложение запускается как дополнение строки меню. Переместите указатель в область 6 px в центре верхнего края текущего дисплея или выберите «Show Island» у значка строки меню.

Чтобы проверить интервал в 5 секунд в отладочной сборке, выполните `ZISLA_DEBUG_PET_ROTATION_SECONDS=5 make run` в корне репозитория. Включите режим «Случайная смена» и добавьте в список не менее двух питомцев. Выполните `make update` без переменной, чтобы вернуться к сохранённому интервалу.

## Интеграция инструментов AI

### Автоматическое обнаружение

zisla читает публичное или стабильное локальное состояние сеансов поддерживаемых инструментов и извлекает только структурированные события и метаданные активности для определения состояния задач. Тексты запросов и ответов не читаются.

| Среда | Автоматическое обнаружение |
| --- | --- |
| OpenAI / Anthropic | Codex CLI и Desktop, Claude Code и их среды запуска |
| GitHub / Google / xAI | GitHub Copilot CLI и VS Code, Gemini CLI и Desktop, Grok CLI |
| Независимые и региональные инструменты | Pi, Kimi Code, Qwen Code, Qoder, ZCode Desktop и CLI, TRAE, OpenCode, Harnext/Harness и WorkBuddy |

Ожидание разрешения или ответа пользователя отмечается жёлтым, ошибки инструментов/команд — красным, нормальная работа — зелёным; одновременные источники группируются в порядке красный, жёлтый, зелёный. Сопутствующий процесс Qwen считается активным лишь при живом PID, чтобы после выхода не оставались устаревшие сообщения.

Если настольное приложение чата не сохраняет структурированные события, нельзя надёжно отличить открытое бездействующее приложение от генерации модели. Такие инструменты, включая ChatGPT, должны использовать хук `zislactl` ниже; zisla не имитирует активность постоянным процессом.

### Локальный протокол `zislactl`

`zislactl` записывает состояние задач и историю использования в SQLite:

```text
~/Library/Application Support/zisla/ai-state.sqlite
```

История сохраняется после перезапусков, обновлений с заменой и очистки задач. Она удаляется только при ручном удалении данных приложения пользователем.

Пример:

```bash
swift run zislactl update \
  --id build-42 \
  --provider claude \
  --title "Refactor index" \
  --progress 68 \
  --detail "17/25"

swift run zislactl usage \
  --provider claude \
  --input-tokens 12400 \
  --output-tokens 2100 \
  --model claude-opus-4-8

swift run zislactl finish --id build-42 --detail "Complete"
```

Канонические провайдеры: `claude`, `codex`, `gemini`, `grok`, `gpt`, `copilot`, `kimi`, `qwen`, `coder`, `zcode`, `trae`, `opencode`, `pi`, `harness` и `doubao`; распространённые псевдонимы нормализуются автоматически. Вызывайте из любого хука, оболочки shell или скрипта задачи.

Список задач AI и свёрнутое состояние используют официальные логотипы для обозначения источника.

Протокол описан в [справочнике CLI](Docs/cli-reference.md).

## Прогресс загрузок браузера

zisla слушает публичные данные macOS о прогрессе файлов в каталоге Downloads и определяет источник по расширениям временных файлов, расширенным атрибутам источника и запущенным браузерам. Она не читает историю браузера и не делает сетевых запросов для определения прогресса; отметка завершения остаётся около трёх секунд. Быстрые действия используют тот же источник событий и предлагают открыть папку после успешного перемещения в итоговое расположение. Длительность подсказки задают настройки Быстрых действий; последняя подсказка копирования или передачи заменяет предыдущую.

## Загрузчик

Порядок поиска исполняемых файлов:

1. `zisla.app/Contents/Helpers/yt-dlp`
2. `/opt/homebrew/bin/yt-dlp`
3. `/usr/local/bin/yt-dlp`
4. `~/.local/bin/yt-dlp`

URL передаётся `Process` отдельным аргументом argv без shell. Конфигурация и плагины выполнения игнорируются, `--exec` отключён, ограничение одного элемента принудительно, итоговый файл проверяется на нахождение внутри разрешённого каталога.

Без `ffmpeg`:

- Видео предпочитает дорожки AVC/MP4 и M4A, затем упаковывает их в MP4 через AVFoundation; единый файл сохраняется без изменений.
- Аудио предпочитает M4A, иначе сохраняется исходный формат.
- При HTTP 412, отсутствии формата или локального yt-dlp Bilibili получает дорожки DASH через API только для чтения и использует ту же нативную упаковку без установки другого инструмента.

## Заметки

Markdown-заметки острова используют Apple Notes как единственный источник. Можно создавать, просматривать, редактировать и удалять существующие заметки, а не только добавлять новые.

- **Список:** При входе JXA (`osascript -l JavaScript`) читает названия и даты изменения неудалённых заметок и сортирует по последнему изменению. Возврат из Notes обновляет список; Recently Deleted скрывается. Выберите заметку для редактирования, обновите, создайте или удалите через контекстное меню.
- **Просмотр и редактирование:** AppleScript читает `plaintext` выбранной заметки (исходный Markdown) в редактор. Нативный `TextEditor` записывает изменения после примерно 0,8 секунды бездействия, чтобы не вызывать AppleScript при каждом нажатии. Новая заметка создаётся в Apple Notes и выбирается.
- **Предпросмотр:** Встроенный блочный анализатор отображает заголовки, обычные/нумерованные/задачные списки, цитаты, блоки кода, разделители, жирный и курсивный текст, встроенный код, зачёркивание и ссылки как `AttributedString`.
- **Хранение:** Исходный Markdown хранится обычным текстом в `body` заметки с HTML-экранированием и сохранёнными пустыми строками. Чтение `plaintext` восстанавливает исходник; Apple Notes отображает обычный текст, не Markdown.
- **Разрешения:** Первое чтение/запись вызывает разрешение автоматизации macOS для Apple Notes; отказ возвращает уведомление ошибки списка или редактора.

Модуль не хранит вторую локальную копию; сервером хранения служит Apple Notes.

## Разрешения и конфиденциальность

- **Календарь:** При первом входе отдельно запрашиваются Календари и Напоминания; данные обновляются после создания, удаления или завершения.
- **Местоположение:** Погода однократно запрашивает текущее место без постоянного слежения; другие места находятся, сохраняются и удаляются в Настройках.
- **Файлы и загрузки:** Выбранные каталоги используют закладки с ограниченной областью доступа; передача не копирует оригинал.
- **Буфер:** Новые установки включают историю и распознавание ссылок независимыми переключателями. Для каждого `changeCount` локально распознаётся не более одной ссылки; параметры запроса не журналируются, API очистки, объявления типа или записи не вызываются, поэтому универсальный буфер не заменяется.
- **Быстрые действия:** При включении работают локально на каждом `changeCount` и обрабатывают завершённые загрузки/полученные AirDrop-файлы. Модификаторы и боковые кнопки могут требовать мониторинга ввода; необязательный жест быстрого копирования также отправляет синтетическое ⌘C и требует Accessibility. Распознавание не подключается к сети; открытие, поиск, перевод и сохранение происходят только по явному нажатию или триггеру. Исключения приложений и переключатели типов управляют подсказками копирования; общий переключатель также управляет подсказками передачи.
- **Состояние AI:** Автоматическое обнаружение читает только структурированные события и нужные локальные метаданные.
- **Голос:** Микрофон и распознавание доступны лишь после явного действия. Записи, исходные транскрипты и обработанный текст управляются локально; текст отправляется только выбранной модели, удалённому провайдеру или профилю CLI, а удалённые учётные данные хранятся в приватной базе.
- **Bluetooth и устройства:** Батареи аксессуаров и доверенных мобильных устройств Apple читаются только при открытом представлении батареи в Системе.
- **Камера и мониторинг ввода:** Зеркало и предпросмотр/запись камеры студии запрашивают камеру. Звуки, статистика, очистка клавиатуры и модификаторные/мышиные триггеры используют мониторинг ввода; статистика локальна, переключатели независимы.
- **Экран и системный звук:** Скриншоты, запись и предпросмотр окон читают экран с разрешением записи экрана. Запись сохраняет выбранные источники локально; микрофон/камера запрашиваются только при включении. Микшер приложений требует macOS 14.4+ и записи системного звука, используя локальные taps Core Audio.
- **Загрузки браузера:** Проверяются только публичный системный прогресс и временные файлы; история и содержимое страниц не читаются.
- **Медиа:** MediaRemote даёт метаданные, состояние выходов процессов Core Audio подтверждает воспроизведение. MediaRemote — приватный framework, поэтому текущая сборка не подходит для прямой отправки в Mac App Store; отсутствие метаданных показывает активное приложение звука.
- **Сеть:** Прогнозы обращаются к China Weather, Open-Meteo и MET Norway с учётом региона и запрашивают другие источники, если данных не хватает. Официальные предупреждения запрашиваются отдельно у China Weather или WeatherKit. Канал обновлений один раз за запуск определяет страну публичного выхода через `ipinfo.io/country`: `CN` — Gitee затем GitHub, другие страны — GitHub затем Gitee, недоступный ответ — Gitee первым. Резерв Bilibili использует данные видео, URL воспроизведения и CDN только для чтения; распознавание ссылок не подключается к сети. Включённые проверки лимитов обращаются к провайдерам; перевод, AI-редактирование записей и обработка транскриптов — к выбранной модели/CLI. Распознавание речи может обращаться к Apple в зависимости от системы/языка. Установка/обновление компонентов и CLI, публичный IP и явно выбранные сетевые действия также делают запросы.
- **Автоматизация:** AppleScript/JXA перечисляет, просматривает, редактирует, создаёт и удаляет Apple Notes. Требует разрешения автоматизации, не использует сеть, хранит данные в Apple Notes.

## Системные ограничения

- macOS не имеет публичного API Dynamic Island; физический вырез определяется через `safeAreaInsets` и верхнюю вспомогательную область, дисплеи без выреза используют то же собственное наложение.
- DRM-видео, окна входа, экран блокировки и часть эксклюзивных полноэкранных приложений могут не предоставлять данные воспроизведения или не разрешать наложение.
- Приложения без интеграции системного медиацентра могут показать источник звука, но не гарантируют название, обложку и прогресс; приостановленное, остановленное и заглушённое видео намеренно скрыто.
- Для процентов браузер должен публиковать прогресс macOS или использовать узнаваемые временные файлы Downloads.
- Здоровье батареи, температура, текущая мощность и заряд аксессуаров зависят от оборудования, подключения и данных macOS; отсутствующие поля показываются недоступными.
- Office в PDF требует LibreOffice/OpenOffice; другие операции PDF выполняются локально.
- Пакеты не нотарифицированы и могут требовать **Open Anyway** при первом запуске. Стабильные выпуски используют один самоподписанный сертификат для сохранения разрешений macOS после обновления; Sparkle отдельно проверяет каждое обновление встроенным открытым ключом EdDSA перед извлечением, заменой и перезапуском.
