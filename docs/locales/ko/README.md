# zisla

[English](../../../README.md) | [简体中文](../../../README.zh-CN.md) | **한국어** | [다른 언어](../README.md)

**zisla는 필요할 때 나타나고 작업이 끝나면 숨는 macOS 네이티브 작업 공간입니다.** 포인터를 화면 상단 중앙으로 옮기면 AI 작업, 미디어, 파일 전달, 다운로드와 데스크탑 도구를 한곳에서 확인합니다. 노치가 없는 화면에도 같은 형태의 상태 영역을 표시합니다.

현재 **macOS 14+**를 지원합니다. Apple Silicon이 지원 대상입니다. Intel 패키지가 동작할 수 있지만 호환성을 보장하지 않습니다.

## 화면 상단에 두는 이유

- **필요할 때 열며 포커스를 빼앗지 않습니다.** 상단에서 펼치고 고정한 채 현재 앱에서 작업합니다.
- **진행 중인 일을 모읍니다.** 재생, AI, 다운로드, 타이머, 메일, 시스템과 배터리를 별도 대시보드 없이 봅니다.
- **대화 접근 없이 AI 상태를 봅니다.** 상태 판단에 필요한 구조화 이벤트와 로컬 메타데이터만 읽고 프롬프트나 답변 본문은 읽지 않습니다.
- **설정은 로컬입니다.** 모듈, 클립보드 기록과 링크 인식은 독립적이며 기능이 처음 필요로 할 때 권한을 요청합니다.

## 할 수 있는 일

### 데스크탑 작업 이어가기

| 기능 | 내용 |
| --- | --- |
| 재생 중 | 표지, 제목, 진행, 가사와 제어. 정보가 없으면 Core Audio로 실제 소리를 내는 앱을 찾습니다. |
| 전달과 공유 | 파일, 오디오·영상, 링크를 상단에 놓아 선반에 보관하고 Finder에서 표시하거나 공유합니다. 선택한 파일과 폴더를 ZIP으로 압축하고, 이미지를 이미지 도구에서 크기 조정하거나 형식 변환한 뒤 성공한 결과를 선반으로 돌려보냅니다. 이미지·영상·오디오는 현재 프로젝트와 타임라인을 유지하며 녹화 미디어 라이브러리에 가져옵니다. |
| 클립보드와 알림 | 선택적 로컬 기록과 링크 인식. 접힌 상태에서 미디어, AI, 다운로드, 타이머, 메일, 업데이트를 봅니다. 복사 후 빠른 작업은 미리보기와 열기, Finder, 검색, 번역, 계산, 저장을 제공합니다. 브라우저나 AirDrop 완료 후 같은 키로 폴더를 열 수 있습니다. 새 기록 이미지는 기기 내 문자 인식 대기열에 들어갑니다. 이미지 안의 문자로 원본 이미지를 찾거나 오른쪽 클릭으로 문자를 인식·복사합니다. |
| 일상 공간 | 날씨, 캘린더, 미리 알림, Mail.app, Apple 메모 기반 Markdown 메모, 잠금 화면 정보와 선택적 펫. |

### AI 작업 보기

Codex, Claude Code, Pi, GitHub Copilot, Gemini, Grok, Kimi Code, Qwen Code, Qoder, ZCode, Zed Agent, Delta, Orca, TRAE, OpenCode, Harnext, WorkBuddy, WorkBuddy AI와 지원 로컬 소스의 작업, 상태, token 추이, 활동 히트맵과 알림을 표시합니다.

안정적 로컬 소스가 없는 도구는 `zislactl`로 스크립트, CI, hook의 진행·사용량·알림을 보고하며 상태는 이 Mac에 남습니다. 설정에서 AI CLI 감지·설치·업데이트·삭제와 로컬 Skills 관리도 할 수 있습니다. [CLI 참조](mac/Docs/cli-reference.md)를 확인하세요.

### 작은 작업 처리하기

| 분야 | 도구 |
| --- | --- |
| 다운로드와 문서 | `yt-dlp`로 영상과 오디오를 다운로드합니다. 로컬 PDF의 병합, 분할, 회전, 자르기, 변환, 렌더링, 텍스트 내보내기, 워터마크, 페이지 번호, 암호화, 해제와 메타데이터 편집을 지원합니다. |
| 집중과 발표 | 끝날 때 한 번 소리와 로컬 알림을 내는 포모도로, 화면 유지, 유휴 잠자기 방지, 화면·키보드 청소, 프롬프터와 카메라 거울. |
| 시스템과 배터리 | CPU, GPU, 메모리, 디스크, 네트워크, 팬, 배터리와 안전하게 지울 수 있는 캐시·로그 정리. |
| 음성 입력 | 전역 키 녹음·전사, 선택적 로컬/원격 정리와 로컬 기록. |

### 현재 진입 위치와 작업 흐름

아일랜드는 홈, 선반, 클립보드, AI, 키보드 소리, 다운로드, 일정, 메일, 메모, 앱 믹서, 도구, 시스템의 12개 모듈입니다. 배터리는 시스템 안에 있고 잠금 화면은 독립적입니다. PDF·이미지·오디오는 설정, 녹화 스튜디오는 설정이나 메뉴 막대에서 엽니다.

- **녹화와 제작:** 화면·창·영역과 선택한 시스템 소리·마이크·카메라. 여러 트랙에서 자막, 확대, 인물·음성 효과를 편집하고 미리보기 후 영상, GIF, Live Photo 또는 오디오로 내보냅니다. 이미지 9개, 오디오 27개 작업입니다.
- **믹싱과 재생:** macOS 14.4+ 앱별 음량과 음소거, 미디어 영역 출력 장치와 설정의 선호 플레이어.
- **데스크탑과 회의:** Dock/Command+Tab 미리보기, 페이지·창·데스크탑 위치 메모, 시작 10분 전 회의 카운트다운과 참여·메모 연결. 드래그하며 흔들면 선반 목표를 표시합니다.
- **일일 브리핑:** 8개 템플릿, 미리보기, 수동·예약 PNG, 통계 선택과 별도 폴더.
- **AI 계정:** 남은 한도, 재설정, 부족 알림, 샘플 시각과 로컬 token .xlsx 내보내기.
- **빠른 작업:** Command+1부터 Command+0까지 순서대로. 새 설정의 추가 Command+N은 첫 동작이며 저장한 키와 해제 상태는 업데이트해도 유지합니다.

[사용자 도움말](https://wzz6423.github.io/zisla/help.html?lang=ko#help)은 클립보드, 화면 캡처·녹화, 선반, 회의, AI, 미디어 도구, 일일 브리핑, 위치 메모·창 미리보기, 재생·믹싱의 9가지 단계별 가이드와 짧은 영상을 제공합니다. [macOS 가이드](mac/README.md#저장-위치)에서 폴더와 의존성을 확인합니다.

## 시작하기

### 앱 설치

최신 DMG를 [GitHub](https://github.com/wzz6423/zisla/releases) 또는 [Gitee](https://gitee.com/wzz6423/zisla/releases)에서 받아 마운트하고 zisla.app을 Applications로 드래그합니다.

Homebrew도 가능합니다:

```bash
brew install --cask wzz6423/tap/zisla
```

칩에 맞는 단일 아키텍처를 받습니다. Homebrew 공식 저장소가 아닌 `wzz6423/tap`을 신뢰하는 설치입니다. 실행 후 상단 중앙으로 포인터를 옮기거나 메뉴에서 아일랜드 표시를 선택합니다. 공증되지 않아 처음에는 **시스템 설정 > 개인정보 보호 및 보안 > 그래도 열기** 또는 격리 속성 제거가 필요합니다:

```bash
xattr -d com.apple.quarantine /Applications/zisla.app
```

### 앱 업데이트

어떤 방법으로 설치해도 Sparkle이 업데이트합니다. Homebrew 5.1.6+의 일반 brew upgrade는 앱 내부 버전을 읽어 tap보다 오래된 경우만 바꿉니다. cask 이름 지정은 설치 기록을 사용해 Sparkle 버전을 되돌릴 수 있습니다:

```bash
brew upgrade --cask zisla
```

tap은 안정판만, Preview는 Releases에서 받습니다. 일반 업그레이드는 prerelease로 가지 않습니다. Preview에서 이름 지정은 안정판으로 바꿉니다. Sparkle은 다운그레이드하지 않아 Release로 돌리면 Preview를 넘는 안정판을 기다립니다. `brew uninstall --cask zisla`는 앱을 삭제하고 `brew uninstall --zap --cask zisla`는 로컬 데이터도 삭제합니다.

### 소스 실행

Swift 6 / Xcode 16 이상이 필요합니다. Command Line Tools만으로도 빌드할 수 있습니다.

```bash
cd mac
swift run zisla
```

yt-dlp 필요, ffmpeg 선택, Office-to-PDF는 LibreOffice/OpenOffice가 필요합니다. [macOS 가이드](mac/README.md)에 빌드·테스트·패키징이 있습니다.

## 작업을 방해하지 않는 설계

- 다중 화면, Spaces, 일반 전체화면에서 포커스를 빼앗지 않습니다.
- 숨을 때 투명 영역이나 프레임 루프 없이 이벤트와 위치로 펼칩니다.
- 소재 한 층만 쓰며 투명도 감소에서는 불투명해집니다.
- 안전 영역으로 노치를 감지하고 외장 화면에도 같은 모양을 씁니다.

[아키텍처](mac/Docs/architecture.md)에 설계 선택이 있습니다.

## 개인정보와 권한

켜진 기능이 처음 필요로 할 때 요청합니다. 기능을 끄거나 시스템에서 취소할 수 있습니다.

| 분야 | 경계 |
| --- | --- |
| AI | 구조화 이벤트와 로컬 메타데이터만, 본문 읽기 없음. |
| 클립보드·파일 | 기록·링크·빠른 작업 독립, 전송 알림은 다운로드 진행과 별도. 인식 로컬, 실행은 명시적 클릭·키 후. 파일은 보안 책갈피 참조. |
| 메모·메일·음성 | AppleScript/JXA와 자동화, 활성 음성만 녹음, 전사는 선택 모델/Provider/CLI에만 전송. |
| 브라우저·미디어 | 공개 진행·MediaRemote·Core Audio. 브라우저 기록 없음, 파형·믹서 로컬, 켜진 소리만 녹화 저장. |
| 네트워크 | 날씨·공개 IP·업데이트 경로·다운로드·한도·의존성과 CLI 설치. 번역·음성·녹화 AI는 선택 서비스, Apple 인식은 언어와 시스템에 따름. |

### 기능별 권한

첫 사용 시 권한을 요청합니다. 이전에 거부했다면 **시스템 설정 > 개인정보 보호 및 보안**에서 해당 항목을 열고 `zisla`를 허용하세요. 명칭은 macOS 버전에 따라 다릅니다.

| 권한 | 필요한 상황 | 범위 |
| --- | --- | --- |
| 장치 제어/데이터 접근 또는 손쉬운 사용 | 현재 입력란에 음성 삽입 | 비밀번호가 아닌 입력란을 찾아 접근성 API 또는 `Cmd+V`로 삽입합니다. 권한 없이도 전사문은 클립보드에 복사합니다. |
| 마이크 | 음성·스튜디오 | 선택한 녹음/모니터 입력. |
| 음성 인식 | 전사 | 녹음 음성만, 마이크와 함께 필요. |
| 전체 디스크 | Mail 미실행 인덱스 | `~/Library/Mail` 계정·발신자·제목·요약·시각·읽음. |
| 자동화 | Mail와 Apple 메모 | 읽기·쓰기·회신·삭제·표시. 앱별 취소 가능. |
| 캘린더/미리 알림 | 일정 | 각각 읽고 관리. |
| 위치 | 현재 날씨 | 일회성, 수동 장소는 불필요. |
| 카메라 | 거울·스튜디오 | 해당 기능 활성 카메라. |
| 입력 모니터링 | 키 소리·통계·청소·보조키/마우스 | 관련 이벤트, 로컬 통계. 일반 전역 키는 불필요. |
| Bluetooth | 시스템 배터리 | 연결·페어링 기기의 공개 배터리. |
| 화면·시스템 오디오 기록 | 캡처·미리보기·녹화·파형·믹서 | 선택 원본, 로컬 저장, 믹서는 14.4+. |
| 알림 | 포모도로 | 한 번 소리와 로컬 알림. |
| 선택한 폴더 | 파일·가져오기·내보내기 | 선택 범위만, 전체 디스크 불필요. |

권한 취소는 관련 기능만 끕니다. 변경 후 안 되면 종료하고 다시 엽니다. [macOS 가이드](mac/README.md#권한과-개인정보)를 확인하세요.
