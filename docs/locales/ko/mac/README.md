# macOS용 zisla

**한국어** | [English](../../../../mac/README.md) | [简体中文](../../../../mac/README.zh-CN.md) | [다른 언어](../../README.md)

이 디렉터리는 zisla의 macOS 구현을 설명합니다. 포인터를 화면 상단 중앙으로 옮기면 아일랜드가 펼쳐지고, 다른 곳으로 옮기면 숨겨집니다. AppKit `NSPanel`, SwiftUI와 이벤트 기반 서비스를 사용하며, 숨긴 상태에서 영구 투명 입력 창이나 프레임 루프를 실행하지 않습니다.

Swift 대상, 번들 ID, 로컬 데이터 디렉터리와 `zislactl`은 모두 zisla 식별자를 사용합니다. 업데이트할 때 이전 버전의 데이터와 환경설정을 자동으로 이전합니다.

macOS 14 이상을 지원합니다. macOS 26에서는 Liquid Glass를, macOS 14/15에서는 기본 시스템 재질을 사용합니다.

## 기능

### 모듈을 연결하는 기능

- **재생 중인 미디어:** MediaRemote가 표지, 제목, 진행, 스크롤 가사와 제어를 제공합니다. Core Audio가 실제 오디오 출력 앱을 대체 원본으로 찾습니다. 일시정지, 정지 또는 음소거된 원본은 숨깁니다.
- **브라우저 다운로드:** Safari, Chrome, Edge, Firefox, Brave, Vivaldi, Opera와 Arc의 원본과 진행을 홈, 접힌 화면과 측면 알림에 표시합니다. 시스템 임시 폴더에 `.crdownload` 파일이 생겼다는 이유만으로 다운로드 카드가 표시되지는 않습니다.
- **음성 입력:** 전환 방식 또는 누르고 말하기, 사용자 지정 전역 단축키, 시스템 음성 인식, 로컬·원격 전사문 정리와 로컬 녹음 기록을 지원합니다.
- **빠른 작업:** 복사할 때마다 작은 아일랜드 알림에서 미리보기와 다음 작업을 선택합니다. 링크 열기, Finder 표시, 선택한 검색 엔진 검색, 번역, 계산, 인식한 날짜로 일정 만들기, 긴 텍스트·이미지 저장을 제공합니다. 브라우저 다운로드나 AirDrop 전송이 완료되면 같은 키로 폴더를 열 수 있습니다. 이 동작은 빠른 작업 설정을 따르며 브라우저 진행 표시와 독립적입니다. URL, 파일 경로, 이메일, 전화번호, 색상 견본이 있는 CSS 색, 계산, 날짜·시간, 시스템과 다른 언어, 코드, 글자 수가 있는 텍스트, 썸네일 이미지와 파일 참조를 인식합니다. 버튼, 추가 기본키 `Command+N`, 설정한 보조키 또는 마우스 측면 버튼으로 실행합니다. 왼쪽 버튼을 누른 채 오른쪽 클릭하는 복사 동작은 기본적으로 꺼져 있습니다. 앱 제외 목록, 유형별 인식 설정과 가벼운 알림 모드도 제공합니다.
- **CLI와 Skills 관리:** 설정에서 일반적인 AI CLI를 감지, 설치, 업데이트, 제거하고 로컬 Skills를 관리합니다.
- **데스크톱 펫:** 설정 → 펫에서 내장 펫과 가져온 펫을 미리 볼 수 있습니다. ‘펫 고정’은 선택한 한 마리를 계속 표시합니다. ‘무작위 교체’는 기본적으로 현지 시간 자정마다 모든 펫 중에서 하나를 뽑습니다. ‘추첨 대상’에서 후보를 고를 수 있습니다. ‘교체 간격’에서 ‘사용자 설정’을 선택하면 1초부터 99시간 59분 59초까지 지정할 수 있습니다. 초깃값은 1시간입니다. 펫은 아일랜드 왼쪽이나 오른쪽에 놓을 수 있습니다. 한 화면에서 아일랜드를 펼쳐도 다른 화면의 펫은 제자리에 머뭅니다.
- **업데이트:** Release 또는 Preview 채널은 실행마다 공개 IP의 국가 코드를 한 번 조회합니다. `CN`은 서명된 Gitee appcast를 먼저 확인하고 GitHub를 한 번 재시도합니다. 다른 국가는 반대 순서이며 조회 실패 시 Gitee를 먼저 사용합니다. Sparkle이 다운로드, 검증, 설치와 재시작을 수행합니다. 채널 변경은 자동·수동 확인에 모두 적용됩니다.
- **모양과 조작:** 시스템, 밝은 모드 또는 어두운 모드를 선택합니다. 투명·반투명 재질, 펼친 상태 고정, 여러 화면, Spaces와 노치 없는 외부 화면을 지원합니다. 브라우저가 전체 화면일 때 아일랜드에 포인터를 올리면 같은 데스크탑에서 펼쳐집니다.
- **기본 설정:** 새 설치에서는 기능 모듈을 켭니다. 기능, 접힌 상태 표시, 측면 알림, 메뉴 막대 통계와 업데이트는 각각 설정할 수 있으며 기존 설치의 설정은 유지합니다.
- 여러 디스플레이를 연결하면 설정 → 일반 → 디스플레이 모드에서 화면마다 Dynamic Island 모드(카메라 또는 사용자 위치), 노치 모드, 숨기기를 선택할 수 있습니다. 화면이 하나면 이 설정을 숨기고 전체 외관 설정을 사용하며, 다시 연결하면 각 화면의 저장된 설정을 복원합니다. 표시가 활성화된 모든 화면에 접힌 아일랜드가 동시에 표시됩니다. 펼치기, 빠른 작업, 녹음, 임시 메시지는 해당 화면의 아일랜드만 대체합니다. 알림 표시 화면을 선택해도 대기 중인 아일랜드는 숨겨지지 않습니다.

### 독립 도구와 작업 흐름

- **녹화 스튜디오:** 메뉴 막대나 설정에서 엽니다. 화면, 창 또는 영역을 녹화하며 시스템 오디오, 마이크와 카메라를 선택적으로 켭니다. 영상·오디오·이미지·텍스트를 여러 트랙에서 편집하고 자막, 확대, 애니메이션, 인물·음성 효과를 조절합니다. 미리보기 후 영상, GIF, Live Photo 또는 오디오로 내보냅니다. 일부 형식은 FFmpeg가 필요하고 HDR은 지원 기기에 따라 달라집니다. 선반의 미디어를 라이브러리에 가져오며 현재 프로젝트와 타임라인을 유지합니다.
- **이미지·오디오·PDF 도구:** 설정에서 독립 도구를 엽니다. 이미지는 로컬 작업 9개와 일괄·ZIP 내보내기를 지원합니다. 오디오는 믹싱, LUFS 정규화와 노이즈 처리를 포함한 27개 작업을 제공하며 FFmpeg와 ffprobe가 필요합니다. PDF는 14개 작업을 제공하고 Office 변환에는 LibreOffice 또는 OpenOffice가 필요합니다.
- **일일 브리핑:** 설정에서 8개 템플릿과 통계를 선택해 미리 보고 PNG를 수동 또는 매일 지정한 시각에 내보냅니다. 사용할 수 없는 지표는 측정된 0으로 표시하지 않습니다.
- **창 미리보기:** Dock에 포인터를 올리거나 Command+Tab을 사용한 뒤 미리보기를 클릭해 창을 활성화합니다. 설정에서 기능과 권한을 관리합니다.
- **위치 메모와 회의:** 설정한 메모 키를 누른 채 포인터를 흔들면 웹페이지, 창 또는 데스크톱에 메모를 붙입니다. 회의 링크가 있는 이벤트는 시작 10분 전부터 카운트다운하며 참가, 새 메모 또는 기존 메모 연결을 지원합니다. 위치 메모는 선반에서 관리합니다.
- **흔들어 놓기:** 파일을 끄는 중 포인터를 흔들면 놓기 영역이 표시됩니다. 설정에서 별도로 켜고 끕니다.
- **오디오 출력과 플레이어:** 미디어 영역에서 출력 장치를 선택합니다. 설정에서 자동 원본 또는 선호 플레이어, 작은 미디어 표시와 환경음 정지 조건을 선택합니다.
- **AI 잔량과 초기화:** AI 모니터와 설정에서 계정 잔량, 측정 시각, 초기화 시각, 부족 알림과 지원되는 5h/7d 창·Cursor USD 예산을 표시합니다. 로컬 토큰 기록과는 별개입니다. Antigravity의 Gemini와 Claude/GPT 한도는 모니터링, 표시, 알림을 각각 설정합니다. Gemini App의 일반 대화 한도는 같은 Google 계정의 웹 Cookie로 조회하며 Gemini CLI는 별도로 모니터링합니다.

### 빠른 작업의 키 순서

빠른 작업 팝업은 현재 작업 순서에 따라 `Command+1`부터 `Command+9`, 이어서 `Command+0`을 할당합니다. 새 설정의 추가 기본키 `Command+N`은 첫 작업을 실행하고 `Command+Delete`는 팝업을 닫습니다. 설정에서 실행키, 마우스 측면 버튼과 작업 순서를 바꿉니다. 업데이트는 이전 `Command+1`, 사용자 키와 지운 실행키 등 명시적으로 저장한 모든 조합을 유지합니다. 새 설정이거나 실행키 필드가 없는 경우에만 N을 적용합니다.

### 저장 위치

설정 → 저장 위치에서 다운로드, 스크린샷, 이미지 도구, 녹화, PDF, 빠른 작업과 일일 브리핑의 폴더를 각각 선택합니다. 새 설정은 `~/Downloads` 아래의 `picture`(스크린샷·이미지), `video`(녹화), `pdf`, `quick`, `daily`를 사용합니다. 오디오 도구는 내보내기 창에서 파일이나 폴더를 선택합니다. 선반은 원본 파일 참조를 유지하고, 스크린샷과 위치 메모 상태는 `~/Library/Application Support/zisla`에서 관리합니다. 녹화 프로젝트는 녹화 폴더에, 빠른 메모의 텍스트는 Apple 메모에 저장합니다.

[사용자 도움말](https://wzz6423.github.io/zisla/help.html?lang=ko#help)에는 클립보드, 화면 캡처·녹화, 선반, 회의, AI, 미디어 도구, 일일 브리핑, 위치 메모·창 미리보기, 재생·믹싱의 9가지 가이드와 짧은 영상이 있습니다.

### 스크린샷 단축키와 보관

스크린샷 도구 모음의 **보관**은 **고정**과 **복사** 사이에 있습니다. 주석과 완료된 스크롤 캡처를 포함한 최종 이미지를 선반에 저장하며 클립보드에는 복사하지 않습니다. PNG, 원본 앱과 캡처 시간 등의 메타데이터는 로컬 SQLite에 저장해 재시작 후에도 유지합니다. **보관한 스크린샷** 분류에는 해당 카드만 표시됩니다.

**형광펜**은 **브러시** 다음에 있으며 반투명 강조선을 그립니다. 끝선과 원형 표시는 기본적으로 켜져 있고 메뉴에서 끌 수 있습니다. **추출**은 **흐림** 다음에 있으며 macOS 피사체·배경 추출과 자유 선택을 지원합니다. 여러 선택 영역은 합쳐지고 전체 선택·지우기도 제공합니다. 선택하지 않은 픽셀은 투명해지며 추출을 취소할 수 있습니다. 모서리 반경은 기본 0입니다. 선택 위의 핸들이나 반경 슬라이더로 조절하고 크기 표시에 `r`이 나타납니다. PNG의 모서리는 투명하며 0으로 되돌리면 원래 픽셀이 복원됩니다.

| 상황 | 작업 | 기본 단축키 |
| --- | --- | --- |
| 전역 | 스크린샷 | `Control+1` |
| 전역 | 스크롤 스크린샷 | `Control+2` |
| 편집기 | 고정 | `Control+1` |
| 편집기 | 보관 | `Control+2` |
| 편집기 | 사각형 | `Control+3` |
| 편집기 | 타원 | `Control+4` |
| 편집기 | 브러시 | `Control+5` |
| 편집기 | 형광펜 | `Control+6` |
| 편집기 | 화살표 | `Control+7` |
| 편집기 | 번호 | `Control+8` |
| 편집기 | 텍스트 | `Control+9` |
| 편집기 | 흐림 | `Control+0` |
| 편집기 | 추출 | `Control+A` |
| 편집기 | 스크롤 캡처 | `Control+B` |
| 편집기 | 복사 | `Enter` |
| 편집기 | 저장 | `Command+S` |
| 편집기 | 실행 취소 | `Command+Z` |
| 편집기 | 다시 실행 | `Command+Shift+Z` |

스크린샷 설정에서 전역·편집기 단축키를 보고 기록합니다. 복사, 저장, 실행 취소와 다시 실행은 표시만 되며 다시 기록할 수 없습니다. 사용자 키는 업데이트 후 유지합니다. 고정은 별도 전역키가 아닌 편집 작업이지만 메뉴 항목은 계속 제공됩니다.

편집기 기본키는 도구 순서대로 `Control+1`…`Control+9`, `Control+0`, `Control+A`, `Control+B`와 다음 문자입니다. `Q`, `M`, `N`, `W`를 건너뛰는 이유는 Command를 잘못 누르면 종료, 최소화, 새 창 또는 창 닫기가 실행되기 때문입니다. 사용자가 기록하는 조합은 허용합니다.

변경하지 않은 이전 배치는 옛 고정·보관 배치를 포함해 한 번 새 기본값으로 바뀝니다. 스크린샷 키를 하나라도 변경했다면 배치를 유지합니다. 새 작업의 기본키가 충돌하면 같은 안전한 순서로 사용하지 않는 Control 조합을 선택하며, 나중에 다시 기록할 수 있습니다.

## 빠른 시작

### 환경

- macOS 14+
- Swift 6 / Xcode 16+. Command Line Tools만으로도 빌드할 수 있습니다
- 선택 사항: `yt-dlp`, `ffmpeg`. Office-PDF 변환에는 LibreOffice 또는 OpenOffice도 필요합니다

Homebrew를 사용하는 경우:

```bash
brew install yt-dlp ffmpeg
brew install --cask libreoffice
```

### 소스에서 실행

```bash
swift run zisla
```

앱은 메뉴 막대 보조 앱으로 시작합니다. 현재 화면 상단 중앙의 6 px 영역으로 포인터를 옮기거나 메뉴 막대에서 “아일랜드 표시”를 선택합니다.

디버그 빌드에서 5초 간격을 시험하려면 저장소 루트에서 `ZISLA_DEBUG_PET_ROTATION_SECONDS=5 make run`을 실행한 뒤 ‘무작위 교체’를 선택하고 펫을 두 마리 이상 포함하세요. 변수 없이 `make update`를 실행하면 저장된 간격으로 돌아갑니다.

### `.app` 빌드

```bash
Scripts/generate-icon.sh
Scripts/build-app.sh
open "dist/zisla.app"
```

공식 `yt-dlp` 도우미를 포함하려면:

```bash
Scripts/fetch-yt-dlp.sh
Scripts/build-app.sh
```

`fetch-yt-dlp.sh`는 고정된 공식 macOS 독립 실행 파일을 다운로드하고 공식 `SHA2-256SUMS`로 검증한 다음 `Tools/yt-dlp`에 설치합니다.

## AI 도구 연동

### 자동 감지

zisla는 공개된 상태 또는 안정된 로컬 세션 상태에서 작업 판단에 필요한 구조화 이벤트와 로컬 메타데이터만 읽습니다. 프롬프트나 답변 본문은 읽지 않습니다.

| 환경 | 자동 감지 |
| --- | --- |
| OpenAI / Anthropic | Codex CLI와 Desktop, Claude Code와 해당 호스트 환경 |
| GitHub / Google / xAI | Copilot CLI와 VS Code, Gemini CLI와 Desktop, Grok CLI |
| 독립·지역 도구 | Pi, Kimi Code, Qwen Code, Qoder, ZCode Desktop와 CLI, TRAE, OpenCode, Harnext/Harness, WorkBuddy |

승인·답변 대기는 노란색, 도구·명령 오류는 빨간색, 정상 실행은 초록색으로 표시합니다. 동시에 감지된 원본은 빨강, 노랑, 초록 순서로 모읍니다. Qwen 런타임 사이드카는 PID가 살아 있을 때만 활성으로 판단해 종료 후 오래된 상태를 막습니다.

대화형 데스크톱 앱이 구조화 활동 이벤트를 저장하지 않으면 열린 유휴 앱과 생성 중인 모델을 신뢰할 수 있게 구별할 수 없습니다. ChatGPT 등은 아래의 `zislactl` 훅을 사용해야 합니다. 상주 프로세스만으로 활동을 만들어 표시하지 않습니다.

### 로컬 `zislactl` 프로토콜

`zislactl`은 작업 상태와 사용량 기록을 SQLite에 씁니다:

```text
~/Library/Application Support/zisla/ai-state.sqlite
```

사용량 기록은 재시작, 앱 교체 업데이트와 작업 지우기 후에도 남습니다. 사용자가 앱 데이터를 수동 삭제할 때만 없어집니다.

예제:

```bash
swift run zislactl update \
  --id build-42 \
  --provider claude \
  --title "Refactor index" \
  --progress 68 \
  --detail "17/25"

swift run zislactl usage \
  --provider claude \
  --input-tokens 12400 \
  --output-tokens 2100 \
  --model claude-opus-4-8

swift run zislactl finish --id build-42 --detail "Complete"
```

정식 제공자는 `claude`, `codex`, `gemini`, `grok`, `gpt`, `copilot`, `kimi`, `qwen`, `coder`, `zcode`, `trae`, `opencode`, `pi`, `harness`, `doubao`이며 일반 별칭은 자동 정규화합니다. 도구 훅, 셸 래퍼 또는 작업 스크립트에서 호출할 수 있습니다.

AI 실행 목록과 접힌 상태는 도구의 공식 로고로 원본을 구분합니다. 프로토콜은 [CLI 참조](Docs/cli-reference.md)를 확인하세요.

## 브라우저 다운로드 진행

zisla는 Downloads 디렉터리의 공개 macOS 파일 진행을 감시합니다. 임시 확장자, 다운로드 원본 확장 속성과 실행 중인 브라우저를 결합해 원본을 구분하며, 브라우저 기록 DB나 진행 감지를 위한 네트워크 요청을 사용하지 않습니다. 완료 표시는 약 3초 유지됩니다. 빠른 작업은 같은 이벤트를 사용하고 전송이 최종 위치에 도달하면 폴더 열기를 제공합니다. 표시 시간은 빠른 작업 설정을 따르고 최신 복사·전송 알림이 이전 알림을 교체합니다.

## 다운로더

다음 순서로 실행 파일을 찾습니다:

1. `zisla.app/Contents/Helpers/yt-dlp`
2. `/opt/homebrew/bin/yt-dlp`
3. `/usr/local/bin/yt-dlp`
4. `~/.local/bin/yt-dlp`

URL은 셸을 거치지 않고 `Process`의 별도 argv로 전달합니다. 런타임 설정과 플러그인을 무시하고 `--exec`를 끕니다. 단일 항목 제한을 적용하며 최종 파일이 허용된 디렉터리 안에 있는지 확인합니다.

`ffmpeg`가 없으면:

- 영상은 AVC/MP4와 M4A 오디오를 우선해 AVFoundation으로 MP4에 묶습니다. 단일 파일 형식은 그대로 유지합니다.
- 오디오는 M4A를 우선하며 다른 경우 원래 형식을 유지합니다.
- yt-dlp가 HTTP 412, 형식 없음 또는 로컬 미설치 상태라면 Bilibili 읽기 전용 API로 DASH를 얻어 같은 기본 결합 경로를 사용합니다. 추가 도구를 설치하지 않습니다.

## 메모

아일랜드의 Markdown 메모는 Apple 메모만 데이터 원본으로 사용합니다. 새 메모뿐 아니라 기존 메모의 조회, 편집과 삭제도 지원합니다.

- **목록:** 진입 시 JXA(`osascript -l JavaScript`)로 삭제되지 않은 메모의 제목과 수정 시각을 읽어 최근 순으로 정렬합니다. Apple 메모에서 돌아오면 새로고침하고 최근 삭제 항목은 숨깁니다. 편집, 새로고침, 생성 또는 오른쪽 클릭 삭제를 선택합니다.
- **조회와 편집:** AppleScript로 선택한 메모의 `plaintext`, 즉 Markdown 소스를 읽습니다. 기본 `TextEditor`는 입력이 약 0.8초 멈춘 뒤 저장하므로 키마다 AppleScript를 호출하지 않습니다. 새 메모는 Apple 메모에 생성되고 선택됩니다.
- **미리보기:** 블록 파서는 제목, 순서 없는·순서 있는·작업 목록, 인용, 코드 블록, 구분선, 굵게, 기울임, 인라인 코드, 취소선과 링크를 `AttributedString`으로 표시합니다.
- **저장:** HTML 이스케이프와 빈 줄을 유지한 일반 텍스트로 Markdown을 `body`에 저장합니다. `plaintext`로 원본을 복원하며 Apple 메모는 Markdown 렌더링 대신 일반 텍스트를 표시합니다.
- **권한:** 첫 읽기·쓰기는 Apple 메모 자동화 권한을 요청합니다. 거부하면 목록이나 편집기에 실패 알림이 표시됩니다.

메모 모듈은 별도의 로컬 사본을 만들지 않으며 Apple 메모를 저장 백엔드로 사용합니다.

## 권한과 개인정보

- **캘린더:** 처음 들어갈 때 캘린더와 미리 알림 권한을 따로 요청하고 생성·삭제·완료 후 갱신합니다.
- **위치:** 날씨는 위치를 한 번 요청하고 계속 추적하지 않습니다. 다른 위치는 설정에서 검색, 저장과 삭제를 수행합니다.
- **파일과 다운로드:** 선택한 디렉터리는 보안 범위 북마크를 사용하며 선반은 원본을 복사하지 않습니다.
- **클립보드:** 새 설치는 기록과 링크 감지를 별도로 켭니다. `changeCount`마다 최대 하나의 링크를 로컬에서 인식합니다. 쿼리를 로그에 남기지 않고 지우기·유형 선언·쓰기 API를 호출하지 않아 유니버설 클립보드를 교체하지 않습니다.
- **빠른 작업:** 켜져 있으면 `changeCount`마다 로컬로 처리하며 완료된 브라우저·AirDrop 전송도 다룹니다. 보조키·마우스 측면 실행에는 입력 모니터링이 필요할 수 있습니다. 선택적 복사 동작은 합성 ⌘C를 보내므로 손쉬운 사용 권한이 필요합니다. 인식은 네트워크를 쓰지 않으며 열기·검색·번역·저장은 명시적 동작 후에 실행합니다. 앱 제외와 유형 설정은 복사 알림을 제어하고 빠른 작업 전체 스위치는 전송 완료 알림도 제어합니다.
- **AI 상태:** 판단에 필요한 구조화 이벤트와 로컬 활동 메타데이터만 읽습니다.
- **음성:** 마이크와 음성 인식은 명시적 사용자 동작 후에 사용합니다. 녹음, 원본 전사와 정리된 텍스트는 로컬로 관리합니다. 텍스트는 선택한 로컬 모델, 원격 제공자 또는 CLI 프로필로만 보내고 원격 인증은 비공개 DB에 보관합니다.
- **Bluetooth와 기기:** 시스템의 배터리 화면이 열려 있을 때만 액세서리와 신뢰된 Apple 모바일 기기의 공개 잔량을 읽습니다.
- **카메라와 입력 모니터링:** 거울과 녹화 카메라의 미리보기·녹화는 카메라 권한을 요청합니다. 키보드 소리, 입력 통계, 청소와 보조키·마우스 실행은 입력 모니터링을 사용합니다. 통계는 로컬이며 스위치는 독립적입니다.
- **화면과 시스템 오디오:** 스크린샷, 녹화와 창 미리보기는 화면 기록 권한으로 화면을 읽습니다. 녹화는 선택한 원본을 로컬 저장하고 마이크·카메라는 켠 경우에만 요청합니다. 앱 믹서는 macOS 14.4 이상과 시스템 오디오 기록 권한이 필요하며 로컬 Core Audio 탭을 사용합니다.
- **브라우저 다운로드:** 공개 파일 진행과 임시 파일만 읽고 기록이나 페이지 본문을 읽지 않습니다.
- **미디어:** MediaRemote가 메타데이터를 제공하고 Core Audio 프로세스 출력 상태로 재생을 확인합니다. MediaRemote는 비공개 프레임워크이므로 현재 빌드는 Mac App Store에 직접 제출할 수 없습니다. 메타데이터가 없으면 활성 원본 앱을 표시합니다.
- **네트워크:** 지역에 따라 중국 날씨망, Open-Meteo, MET Norway에 예보를 조회하고 정보가 부족하면 추가 제공자를 확인합니다. 공식 기상 경보는 중국 날씨망 또는 WeatherKit에서 별도로 가져옵니다. `ipinfo.io/country`로 실행마다 국가를 한 번 조회하며 `CN`은 Gitee, GitHub 순서, 나머지는 반대입니다. 조회 불가 시 Gitee를 먼저 사용합니다. Bilibili는 읽기 전용 영상 정보, 재생 URL과 CDN을 사용하며 링크 인식은 네트워크에 연결하지 않습니다. 계정 잔량 감시는 선택 제공자를 조회하고 번역, 녹화 AI 편집과 전사문 정리는 선택 모델·CLI를 사용합니다. Apple 음성 인식은 시스템·언어에 따라 네트워크를 사용할 수 있습니다. 의존 구성요소·CLI 설치와 업데이트, 공개 IP 조회 및 사용자가 선택한 네트워크 작업도 요청을 보냅니다.
- **자동화:** AppleScript/JXA로 Apple 메모를 목록 조회, 읽기, 편집, 생성과 삭제합니다. 자동화 권한이 필요하고 네트워크는 쓰지 않으며 데이터는 Apple 메모에 남습니다.

## 시스템 제한

- macOS에는 공개 Dynamic Island API가 없습니다. `safeAreaInsets`와 상단 보조 영역에서 노치를 판단하며 노치 없는 화면은 같은 오버레이로 표시합니다.
- DRM 영상, 로그인 창, 잠금 화면과 일부 독점 전체 화면 앱은 재생 정보나 오버레이를 허용하지 않을 수 있습니다.
- 미디어 센터와 연동하지 않는 앱은 오디오 원본만 확인될 수 있으며 제목·표지·진행은 보장하지 않습니다. 일시정지·정지·음소거된 영상은 의도적으로 숨깁니다.
- 브라우저가 공개 macOS 파일 진행이나 Downloads의 식별 가능한 임시 파일을 사용해야 퍼센트를 보여 줄 수 있습니다.
- 배터리, 온도, 전력과 액세서리 잔량은 하드웨어, 연결 방식과 macOS가 제공하는 정보에 따라 다릅니다. 없는 필드는 사용할 수 없음으로 표시합니다.
- Office-PDF는 LibreOffice 또는 OpenOffice가 필요하며 나머지 PDF 작업은 로컬입니다.
- 패키지는 공증되지 않아 첫 실행에 **그래도 열기**가 필요할 수 있습니다. 안정 릴리스는 같은 자체 서명 인증서를 사용해 업데이트 후 권한을 유지합니다. Sparkle은 내장 EdDSA 공개키로 각 업데이트를 검증한 뒤 압축 해제, 교체와 재시작을 수행합니다.
