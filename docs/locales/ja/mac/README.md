# zisla for macOS

**日本語** | [English](../../../../mac/README.md) | [简体中文](../../../../mac/README.zh-CN.md) | [他の言語](../../README.md)

このディレクトリーは zisla の macOS 実装を説明します。ポインターを画面上部中央へ移動するとアイランドが開き、離すと隠れます。AppKit `NSPanel`、SwiftUI とイベント駆動のサービスを使用し、常設の透明ウィンドウや、非表示中の描画ループは使いません。

Swift のターゲット、バンドル ID、ローカルデータディレクトリー、`zislactl` は zisla の識別子を使用します。更新時には以前のバージョンのローカルデータと設定を自動移行します。

macOS 14 以降に対応します。macOS 26 では Liquid Glass、macOS 14/15 ではネイティブのシステム素材を使います。

## 機能

| --- | --- |

### モジュールを横断する機能

- **再生中メディア：** MediaRemote が画像、タイトル、進行、スクロール歌詞、操作を提供します。Core Audio が実際の音源アプリを補完します。一時停止、停止、ミュートされた音源は隠れます。
- **ブラウザーダウンロード：** Safari、Chrome、Edge、Firefox、Brave、Vivaldi、Opera、Arc の出典と進行をホーム、折りたたみ表示、側面通知に表示します。
- **音声入力：** 切り替えまたは押して話すショートカット、独自のグローバルショートカット、システム音声認識、ローカル・リモートの文字整理、ローカル録音履歴に対応します。
- **クイックアクション：** コピー後の小さな通知でプレビューと次の操作を選べます。リンクを開く、Finder 表示、選択した検索エンジンで検索、翻訳、計算、認識した日付から予定を作成、長文・画像の保存に対応します。ブラウザーダウンロードや AirDrop が完了すると同じキーでフォルダーを開けます。この動作はクイックアクションの設定に従い、ダウンロード進行の設定とは独立します。URL、ファイルパス、メール、電話、色見本付き CSS 色、計算、日時、システムと異なる言語の文章、コード、文字数付き文章、サムネイル付き画像、ファイル参照を認識します。入口はボタン、追加既定キー `Command+N`、設定した修飾キーまたはマウス側ボタンです。左ボタンを保持して右クリックするコピー操作は初期無効です。アプリ除外、種類別認識設定、軽量通知モードも用意しています。
- **CLI と Skills：** 設定で一般的な AI CLI を検出、導入、更新、削除し、ローカル Skills を管理します。
- **デスクトップペット：** 内蔵または取り込んだペットをアイランドの左右どちらかへ配置できます。
- **更新：** Release/Preview は実行ごとに公開出口国コードを一度取得します。`CN` では署名済み Gitee appcast を優先して GitHub を一回試し、その他では順序を逆にします。取得不能時は Gitee を優先します。Sparkle が取得、検証、導入、再起動を行います。チャンネル変更は自動・手動両方の確認に適用されます。
- **外観と操作：** システム、明、暗の外観を設定できます。透明または曇り素材、展開固定、複数画面、Spaces、ノッチなし外部画面に対応します。
- **初期設定：** 新規インストールでは機能モジュールを有効にします。各機能、折りたたみ表示、側面通知、メニューバー指標、更新動作は個別設定でき、既存インストールの設定は保持します。

### 独立ツールと作業の流れ

- **録画スタジオ：** メニューバーまたは設定から開きます。画面、ウィンドウ、領域を、任意のシステム音声・マイク・カメラ付きで録画します。動画、音声、画像、文字を複数トラックで編集し、字幕、ズーム、アニメーション、人像・音声効果を調整します。プレビュー後に動画、GIF、Live Photo、音声を出力します。一部の形式には FFmpeg、HDR 録画には対応機器が必要です。棚のメディアを素材ライブラリーに取り込み、現在のプロジェクトとタイムラインを保持できます。
- **画像・音声・PDF ツール：** 設定から独立ツールを開きます。画像は 9 操作と一括・ZIP 出力、音声はミックス、LUFS 正規化、ノイズ処理など 27 操作で FFmpeg と ffprobe が必要です。PDF は 14 操作で、Office 変換には LibreOffice または OpenOffice が必要です。
- **日次レポート：** 設定で 8 テンプレートと統計を選び、プレビューして手動または毎日の指定時刻に PNG を出力します。未取得の指標を測定済みのゼロにはしません。
- **ウィンドウプレビュー：** Dock にポインターを置くか Command+Tab を使い、プレビューをクリックしてウィンドウを切り替えます。設定で機能と権限を管理します。
- **場所メモと会議：** 設定したメモキーを保持しポインターを振ると、ページ、ウィンドウ、デスクトップにメモを付けられます。会議リンク付き予定は開始 10 分前からカウントダウンし、参加、新規メモ、既存メモの連携を選べます。場所メモは棚で管理します。
- **振って投下：** ファイルのドラッグ中に振ると投下先を表示します。設定の独立したスイッチで有効化します。
- **音声出力とプレーヤー：** メディア領域で出力機器を選びます。設定では自動音源または優先プレーヤー、コンパクト表示、環境音の停止条件を選べます。
- **AI 残量とリセット：** AI 監視と設定は対応アカウントの残量、取得時刻、リセット時刻、低残量通知、利用できる 5h/7d 窓と Cursor USD 予算を表示します。ローカル token 履歴とは別の情報です。

### クイックアクションのキー順序

ポップアップは現在の操作順に `Command+1` から `Command+9`、続いて `Command+0` を割り当てます。新規設定の追加既定キー `Command+N` は最初の操作を実行し、`Command+Delete` は閉じます。設定で起動キー、マウス側ボタン、操作順を変更できます。明示保存された旧 `Command+1`、独自キー、解除済みキーはすべて保持します。新規設定またはキーのフィールドがない設定だけが N を採用します。

### 保存先

設定 → 保存先ではダウンロード、撮影、画像ツール、録画、PDF、クイックアクション、日次レポートのフォルダーを個別に選びます。新規は `~/Downloads` の `picture`（撮影・画像）、`video`（録画）、`pdf`、`quick`、`daily` です。音声ツールは出力ダイアログでファイルまたはフォルダーを選びます。棚は元ファイルの参照を保持し、撮影と場所メモ状態は `~/Library/Application Support/zisla` で管理します。録画プロジェクトは録画フォルダー、クイックメモは Apple メモに保存します。

[ユーザーヘルプ](https://wzz6423.github.io/zisla/help.html?lang=ja#help) では、クリップボード、撮影、棚、会議、AI、メディアツール、日次レポート、場所メモ・ウィンドウプレビュー、再生・ミックスの 9 つのガイドと短い映像を利用できます。

### 撮影キーと保管

撮影ツールバーの **保管** は **固定** と **コピー** の間にあります。注釈や完成したスクロール撮影を含む最終編集画像を棚へ保存し、クリップボードにはコピーしません。PNG、元アプリ、撮影時刻などのメタデータはローカル SQLite に保存し、再起動後も残ります。**保管した撮影** の分類にはこのカードだけが表示されます。

**蛍光ペン** は **ブラシ** の次にあり、半透明の線を描きます。端線と円形マーカーは初期有効で、メニューから無効にできます。**抽出** は **ぼかし** の次にあり、macOS の主体・背景抽出や自由選択を使えます。複数の囲みの領域をまとめ、全選択とクリアも利用できます。選択外の画素は透明になり、抽出は取り消せます。角丸半径は初期 0 です。選択上部のハンドルまたはスライダーで変更し、サイズ表示に `r` が付きます。PNG の角は透明で、0 に戻すと元画素を復元します。

| 場面 | 操作 | 既定キー |
| --- | --- | --- |
| 全体 | 撮影 | `Control+1` |
| 全体 | スクロール撮影 | `Control+2` |
| 編集 | 固定 | `Control+1` |
| 編集 | 保管 | `Control+2` |
| 編集 | 四角 | `Control+3` |
| 編集 | 楕円 | `Control+4` |
| 編集 | ブラシ | `Control+5` |
| 編集 | 蛍光ペン | `Control+6` |
| 編集 | 矢印 | `Control+7` |
| 編集 | 番号 | `Control+8` |
| 編集 | 文字 | `Control+9` |
| 編集 | ぼかし | `Control+0` |
| 編集 | 抽出 | `Control+A` |
| 編集 | スクロール撮影 | `Control+B` |
| 編集 | コピー | `Enter` |
| 編集 | 保存 | `Command+S` |
| 編集 | 取り消し | `Command+Z` |
| 編集 | やり直し | `Command+Shift+Z` |

撮影設定でグローバル・編集キーを表示、記録できます。コピー、保存、取り消し、やり直しは表示だけで再記録できません。更新ではユーザーのキーを保持します。固定は独立したグローバルキーではなく編集操作ですが、メニューの入口は残ります。

既定編集キーはツールバー順の `Control+1`…`Control+9`、`Control+0`、`Control+A`、`Control+B` と後続の文字です。`Q`、`M`、`N`、`W` は飛ばします。Command を誤って押すと終了、最小化、新規ウィンドウ、閉じる操作になるためです。ユーザーが記録する組み合わせは許可します。

未変更の旧配列は、以前の固定・保管配列も含め、一度だけ上記の既定値へ移ります。撮影キーを一つでも変更している場合は配列を保持します。新規操作の既定キーが重複する場合は同じ安全な順序で空き Control キーを選び、後から再記録できます。

## クイックスタート

### 環境

- macOS 14+
- Swift 6 / Xcode 16+。Command Line Tools だけでもビルドできます
- 任意の `yt-dlp` と `ffmpeg`。Office-PDF には LibreOffice または OpenOffice も必要です

Homebrew を使用する場合：

```bash
brew install yt-dlp ffmpeg
brew install --cask libreoffice
```

### ソースから実行

```bash
swift run zisla
```

アプリはメニューバーのアクセサリーとして起動します。現在の画面上部中央の 6 px に入るか、メニューバーから「アイランドを表示」を選びます。

### `.app` をビルド

```bash
Scripts/generate-icon.sh
Scripts/build-app.sh
open "dist/zisla.app"
```

公式 `yt-dlp` ヘルパーを含める場合：

```bash
Scripts/fetch-yt-dlp.sh
Scripts/build-app.sh
```

`fetch-yt-dlp.sh` は固定された公式 macOS 単体版を取得し、公式 `SHA2-256SUMS` で確認してから `Tools/yt-dlp` に配置します。

## AI ツール接続

### 自動検出

zisla は公開または安定したローカルセッション状態から、タスク状態の判断に必要な構造化イベントと活動メタデータだけを読みます。プロンプトや回答本文は読みません。

| 環境 | 自動検出 |
| --- | --- |
| OpenAI / Anthropic | Codex CLI と Desktop、Claude Code とそのホスト環境 |
| GitHub / Google / xAI | GitHub Copilot CLI と VS Code、Gemini CLI と Desktop、Grok CLI |
| 独立・地域ツール | Pi、Kimi Code、Qwen Code、Qoder、ZCode Desktop と CLI、TRAE、OpenCode、Harnext/Harness、WorkBuddy |

承認や回答待ちは黄色、ツール・コマンドエラーは赤、通常実行は緑です。複数ソースの状態は赤、黄、緑の順でまとめます。Qwen の実行 sidecar は PID が生きている間だけ活動中と判断し、終了後の古い通知を防ぎます。

会話向けデスクトップアプリが構造化活動イベントを保存しない場合、開いたままのアイドル状態と生成中を確実に区別できません。ChatGPT などは下記の `zislactl` hook を使います。常駐プロセスだけで活動中とは表示しません。

### ローカル `zislactl` プロトコル

`zislactl` はタスク状態と使用量履歴を SQLite に書きます：

```text
~/Library/Application Support/zisla/ai-state.sqlite
```

使用量履歴は再起動、置き換え更新、タスクのクリア後も残ります。アプリデータを手動で削除した場合だけ失われます。

例：

```bash
swift run zislactl update \
  --id build-42 \
  --provider claude \
  --title "Refactor index" \
  --progress 68 \
  --detail "17/25"

swift run zislactl usage \
  --provider claude \
  --input-tokens 12400 \
  --output-tokens 2100 \
  --model claude-opus-4-8

swift run zislactl finish --id build-42 --detail "Complete"
```

正規 Provider は `claude`、`codex`、`gemini`、`grok`、`gpt`、`copilot`、`kimi`、`qwen`、`coder`、`zcode`、`trae`、`opencode`、`pi`、`harness`、`doubao` です。一般的な別名を自動正規化します。ツール hook、shell wrapper、タスクスクリプトから呼び出せます。

AI 実行一覧と折りたたみ表示は各ツールの公式ロゴでソースを示します。プロトコルは [CLI リファレンス](Docs/cli-reference.md) を参照してください。

## ブラウザーダウンロード進行

Downloads ディレクトリーの macOS 公開ファイル進行を監視し、一時ファイル拡張子、取得元の拡張属性、実行中ブラウザーを組み合わせて取得元を判断します。ブラウザー履歴 DB や進行取得のネットワーク接続は使いません。完了表示は約 3 秒残ります。クイックアクションは同じイベント元から、転送が最終保存先へ到達すると「フォルダーを開く」を提供します。通知時間はその設定に従い、最新のコピー・転送通知が前のものを置き換えます。

## ダウンローダー

実行ファイルは次の順で探します：

1. `zisla.app/Contents/Helpers/yt-dlp`
2. `/opt/homebrew/bin/yt-dlp`
3. `/usr/local/bin/yt-dlp`
4. `~/.local/bin/yt-dlp`

URL は shell を通さず `Process` の独立 argv として渡します。実行時設定と plugin を無視し、`--exec` を無効化し、一項目の制限を適用して最終ファイルが許可ディレクトリー内であることを確認します。

`ffmpeg` がない場合：

- 動画は AVC/MP4 と M4A 音声を優先し、AVFoundation で MP4 にまとめます。単一ファイル形式はそのまま保持します。
- 音声は M4A を優先し、それ以外は元形式を保持します。
- yt-dlp が HTTP 412、形式なし、ローカル未導入の場合、Bilibili の読み取り専用 API で DASH を取得し、追加ツールなしで同じネイティブ処理を使います。

## メモ

アイランド内の Markdown は Apple メモだけをデータ元にします。新規作成だけでなく既存メモの閲覧、編集、削除にも対応します。

- **一覧：** 入口で JXA（`osascript -l JavaScript`）が削除されていないメモのタイトルと更新時刻を読み、新しい順に並べます。Apple メモから戻ると更新し、「最近削除した項目」は隠れます。編集、更新、新規作成、右クリック削除を選べます。
- **閲覧と編集：** AppleScript が選択したメモの `plaintext`（Markdown ソース）を読みます。ネイティブ `TextEditor` は約 0.8 秒の入力停止後に書き戻し、毎キーの AppleScript 呼び出しを避けます。新規メモは Apple メモで作成して選択します。
- **プレビュー：** ブロック parser が見出し、番号なし・番号付き・タスクリスト、引用、コードブロック、区切り、太字、斜体、inline code、取り消し線、リンクを `AttributedString` にします。
- **保存：** Markdown ソースを HTML エスケープし空行を保持した通常テキストとして `body` に保存します。`plaintext` で復元し、Apple メモは Markdown ではなくテキスト表示になります。
- **権限：** 最初の読み書きで Apple メモの自動操作を要求します。拒否すると一覧または編集から失敗通知が出ます。

メモモジュールは二つ目のローカルコピーを持たず、Apple メモを保存先にします。

## 権限とプライバシー

- **カレンダー：** 初回にカレンダーとリマインダーを別々に要求し、作成、削除、完了後に更新します。
- **位置：** 天気は現在地を一度取得し、連続追跡しません。ほかの地点は設定で検索、保存、削除できます。
- **ファイルとダウンロード：** 選択したフォルダーは security-scoped bookmark で扱い、棚は元ファイルをコピーしません。
- **クリップボード：** 新規は履歴とリンク検出を独立して有効にします。`changeCount` ごとに最大一つのリンクを端末上で認識し、query を記録せず、clear、型宣言、write API を呼ばないため、ユニバーサルクリップボードを置き換えません。
- **クイックアクション：** 有効時は `changeCount` ごとにローカルで動作し、ブラウザー完了と AirDrop も扱います。修飾キー・マウス側ボタンには入力監視が必要になる場合があり、任意のコピー操作は合成 ⌘C を送るためアクセシビリティが必要です。認識はネットワークを使いません。開く、検索、翻訳、保存は明示操作後です。アプリ除外と種類設定はコピー通知を制御し、全体スイッチは転送完了通知も制御します。
- **AI 状態：** タスク状態の判断に必要な構造化イベントとローカル活動メタデータだけを読みます。
- **音声：** マイクと音声認識はユーザーの明示操作後だけ使います。録音、元の文字、整理済み文字はローカル管理し、整理用文字は選択したモデル、リモート Provider、CLI profile だけへ送ります。リモート認証情報は非公開 DB に保管します。
- **Bluetooth と機器：** システムの電池ビューを開いているときだけ、アクセサリーと信頼済み Apple モバイル機器の公開残量を読みます。
- **カメラと入力監視：** ミラーと録画スタジオのカメラプレビュー・録画はカメラ権限を要求します。キー音、入力統計、清掃、修飾キー・マウス起動には入力監視を使い、統計はローカルで、各スイッチは独立します。
- **画面とシステム音声：** 撮影、録画、プレビューは画面収録権限で画面を読みます。録画は選択音源をローカル保存し、マイク・カメラは有効なものだけ要求します。ミキサーは macOS 14.4+、システム音声収録権限、ローカル Core Audio tap を使います。
- **ブラウザーダウンロード：** 公開ファイル進行と一時ファイルだけを見て、履歴やページ本文を読みません。
- **メディア：** MediaRemote がメタデータを提供し、Core Audio のプロセス出力で再生を確認します。MediaRemote は非公開 framework のため、現在のビルドは直接 Mac App Store へ提出できません。情報がない場合は活動中音源アプリを表示します。
- **ネットワーク：** 地域に応じて Open-Meteo と中国の公開気象警報を使い、その他では WeatherKit を優先します。`ipinfo.io/country` が一度だけ出口国を調べ、`CN` は Gitee、GitHub、その他は逆、取得失敗は Gitee 優先です。Bilibili の情報、再生 URL、CDN は読み取り専用で、リンク認識は接続しません。残量監視は選択 Provider に接続し、翻訳、録画 AI、文字整理は選択モデルや CLI を使います。Apple の音声認識はシステム・言語によってネットワークを使う場合があります。依存部品と CLI の導入・更新、公開 IP、ユーザーが選んだネットワーク操作も接続します。
- **自動操作：** AppleScript/JXA で Apple メモを一覧、閲覧、編集、作成、削除します。自動操作権限が必要で、ネットワークは使わず、データは Apple メモに残ります。

## システム制限

- macOS は公開 Dynamic Island API を持ちません。`safeAreaInsets` と上部補助領域からノッチを推定し、ない画面は同じ overlay で再現します。
- DRM 動画、ログイン、ロック画面、一部の排他的な全画面アプリはメディア情報や overlay を提供しない場合があります。
- システムメディアと連携しないアプリは音源だけを表示でき、タイトル、画像、進行は保証できません。停止、一時停止、ミュート動画は意図的に隠れます。
- ブラウザーが公開ファイル進行または Downloads の認識可能な一時ファイルを使う場合だけ、割合を表示できます。
- 電池健康、温度、電力、機器残量はハード、接続、macOS の情報に依存し、未取得の項目は利用不可と表示します。
- Office-PDF には LibreOffice/OpenOffice が必要で、その他 PDF はローカル処理です。
- パッケージは公証なしで、初回は **このまま開く** が必要な場合があります。安定版は同じ自己署名証明書で更新後の権限を維持し、Sparkle は内蔵 EdDSA 公開鍵で各更新を検証してから展開、置換、再起動します。
