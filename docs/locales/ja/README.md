# zisla

[English](../../../README.md) | [简体中文](../../../README.zh-CN.md) | **日本語** | [他の言語](../README.md)

**zisla は、必要なときに現れ、作業後は隠れるネイティブ macOS ワークスペースです。** ポインターを画面上部中央に移動すると、AI 作業、メディア、ファイル受け渡し、ダウンロード、デスクトップツールを軽量な一か所で確認できます。ノッチのない画面にも同じ形のステータス領域を表示します。

現在は **macOS 14+** に対応します。Apple Silicon がサポート対象です。Intel 用リリースパッケージが動作する場合もありますが、互換性は保証していません。

## 画面上部に置く理由

- **必要なときだけ表示し、フォーカスを奪いません。** 上端から展開し、必要なら固定したまま現在のアプリで作業できます。
- **進行中の作業をまとめます。** 再生中メディア、AI タスク、ダウンロード、タイマー、メール、システム状態、バッテリーを確認できます。
- **会話を読まずに AI の状態を表示します。** タスクの判断に必要な構造化イベントとローカル活動メタデータだけを読み、プロンプトや回答本文は読みません。
- **設定はローカルです。** モジュール、クリップボード履歴、リンク検出は独立して切り替えられ、権限は機能が初めて必要とするときに要求します。

## できること

### デスクトップ作業を続ける

| 機能 | 内容 |
| --- | --- |
| 再生中メディア | アートワーク、曲名、進行、歌詞と操作を表示。メタデータがない場合は Core Audio で実際に音を出すアプリを特定します。 |
| 受け渡しと共有 | ファイル、音声・動画、リンクを上部へドロップして棚に保管し、Finder で表示したり macOS 共有メニューを開けます。 選択したファイルやフォルダーを ZIP に圧縮し、画像を画像ツールでサイズ変更・形式変換して成功した結果を棚へ戻せます。画像・動画・音声を録画素材ライブラリーへ取り込み、現在のプロジェクトとタイムラインを保持できます。 |
| クリップボードと通知 | 任意で履歴をローカル保存し、新しいリンクを端末上で認識。折りたたみ表示はメディア、AI、ダウンロード、タイマー、メール、更新を示します。クイックアクションはコピー後にプレビューと次の操作（開く、Finder、検索、翻訳、計算、保存）を示します。ブラウザのダウンロードや AirDrop 完了後は同じキーでフォルダーを開けます。 新しい履歴画像は端末上の文字認識キューに入り、画像内の文字で元画像を検索できます。右クリックで文字を認識・コピーします。 |
| 日常の作業領域 | 天気、カレンダー、リマインダー、Mail.app、Apple メモを使う Markdown メモ、ロック画面情報と任意のペット。 |

### AI の作業を見えるようにする

Codex、Claude Code、Pi、GitHub Copilot、Gemini、Grok、Kimi Code、Qwen Code、Qoder、ZCode、Zed Agent、Delta、Orca、TRAE、OpenCode、Harnext、WorkBuddy、WorkBuddy AI などのローカル活動源を監視します。タスク、状態、token 推移、貢献ヒートマップと側面通知を表示します。

安定したローカル活動源がないツールは、`zislactl` でスクリプト、CI、hook から進行、使用量、通知を報告できます。状態はこの Mac に保存します。設定で一般的な AI CLI の検出、導入、更新、削除とローカル Skills 管理も行えます。Provider とコマンドは [CLI リファレンス](mac/Docs/cli-reference.md) にあります。

### 小さな作業をまとめる

| 分野 | ツール |
| --- | --- |
| ダウンロードと文書 | `yt-dlp` による動画・音声取得。PDF 結合、分割、回転、切り取り、変換、画像化、文字出力、透かし、ページ番号、暗号化、解除、メタデータ編集。 |
| 集中と発表 | 終了時に一度音とローカル通知を出すポモドーロ、画面維持、アイドルスリープ防止、画面・キーボード清掃、プロンプター、カメラミラー。タイマー名は現在のセッションにのみ適用され、終了またはキャンセルすると既定の名前に戻ります。 |
| システムと電池 | CPU、GPU、メモリー、ディスク、ネットワーク、ファン、電池と安全に削除できるキャッシュ・ログの整理。 |
| 音声入力 | グローバルキーによる録音と文字起こし、任意のローカル・リモート整形、ローカル履歴。 |

### 現在の入口と作業の流れ

アイランドには 12 モジュールがあります：ホーム、棚、クリップボード、AI 監視、キー音、ダウンロード、予定、メール、メモ、アプリ音量ミキサー、ツール、システム。電池はシステム内、ロック画面は独立機能です。画像、音声、PDF は設定から、録画スタジオは設定またはメニューバーから開きます。

- **録画と制作：** 画面、ウィンドウ、領域を、任意のシステム音声、マイク、カメラと録画。字幕、ズーム、人像・音声効果を複数トラックで編集し、プレビューして動画、GIF、Live Photo、音声に出力します。画像は 9 操作、音声は 27 操作です。
- **ミックスと再生：** macOS 14.4+ はアプリ別音量・ミュートに対応。メディア領域で出力機器、設定で優先プレーヤーを選べます。
- **デスクトップと会議：** Dock と Command+Tab のウィンドウプレビュー、ページ・ウィンドウ・デスクトップの場所メモ、開始 10 分前の会議カウントダウン、参加とメモ連携。ファイルをドラッグしながら振ると棚の投下先が現れます。
- **日次レポート：** 8 テンプレート、プレビュー、手動・定時 PNG 出力、統計の選択、独立保存先。
- **AI アカウント：** 対応する残量、リセット時刻、低残量通知、取得時刻。ローカル token 履歴は `.xlsx` 出力できます。 Antigravity の Gemini と Claude/GPT の割当は、監視・表示・通知を個別に設定できます。Gemini App の通常チャットの割当は同じ Google アカウントのウェブ Cookie で取得し、Gemini CLI は別に監視します。
- **クイックアクション：** Command+1 から Command+0 が操作順に対応。新規設定の追加キー Command+N は最初の操作です。更新時も保存済みキーと解除状態を保持します。

[ユーザーヘルプ](https://wzz6423.github.io/zisla/help.html?lang=ja#help) にはクリップボード、撮影、棚、会議、AI、メディアツール、日次レポート、場所メモ・ウィンドウプレビュー、再生・ミックスの 9 つの手順ガイドと短い映像があります。 [macOS ガイド](mac/README.md#保存先) は出力先と依存ツールを記載します。

## 始め方

### アプリの導入

最新 DMG を [GitHub Releases](https://github.com/wzz6423/zisla/releases) または [Gitee Releases](https://gitee.com/wzz6423/zisla/releases) から入手し、マウントして `zisla.app` を `Applications` にドラッグします。

Homebrew でも導入できます：

```bash
brew install --cask wzz6423/tap/zisla
```

Homebrew はチップに対応する build を取得するため、Apple Silicon と Intel はそれぞれ自分の slice だけをダウンロードします。cask は公式 Homebrew リポジトリーではなく第三者の `wzz6423/tap` から配布され、導入はこの tap を信頼することを意味します。

起動後は現在の画面上部中央へポインターを移動するか、メニューバーの「アイランドを表示」を選びます。パッケージは公証されていないため、導入方法にかかわらず初回は **システム設定 > プライバシーとセキュリティ > このまま開く** を選ぶか、隔離属性を自分で削除します：

```bash
xattr -d com.apple.quarantine /Applications/zisla.app
```

### アプリの更新

導入方法を問わず Sparkle が更新します。Homebrew 5.1.6+ はアプリ内のバージョンを読むため、`brew upgrade` は実際のアプリが tap より古い場合だけ置き換えます。名前を指定すると Homebrew の導入記録を使い、Sparkle 更新済みアプリを tap の版に戻す場合があります：

```bash
brew upgrade --cask zisla
```

tap は安定版のみです。Preview は Releases にあり、通常の `brew upgrade` は prerelease に移行しません。Preview で cask 名を指定すると安定版へ置き換えます。Sparkle はダウングレードせず、Release に戻した設定は Preview を超える安定版まで待ちます。`brew uninstall --cask zisla` はアプリを削除し、`brew uninstall --zap --cask zisla` はローカルデータも削除します。

### ソースから実行

Swift 6 / Xcode 16+ が必要です。Command Line Tools のみでもビルドできます。

```bash
cd mac
swift run zisla
```

取得ツールには `yt-dlp` が必要で、`ffmpeg` は任意です。Office-to-PDF は LibreOffice または OpenOffice を使います。ビルド、テスト、パッケージ手順は [macOS ガイド](mac/README.md) にあります。

## 作業を邪魔しない設計

- 複数画面、Spaces、通常の全画面で、アプリのフォーカスを奪いません。
- 非表示に透明なヒット領域やフレームループを持たず、イベントと幾何で展開します。
- システム素材は一層で、透明度を下げる設定では不透明です。
- safe area で物理ノッチを検出し、外接ノッチなし画面も同形 overlay を使います。

設計上の選択は [アーキテクチャ](mac/Docs/architecture.md) にあります。

## プライバシーと権限

権限は有効な機能が初めて必要とするときに要求します。機能やシステム設定で取り消せます。

| 分野 | 境界 |
| --- | --- |
| AI 活動 | 構造化イベントとローカルメタデータだけ。プロンプト・回答本文は読みません。 |
| クリップボードとファイル | 履歴、リンク検出、アクションは独立したローカル設定。転送完了アクションはダウンロード進行設定と別。認識は端末内で、クリックやキー操作後だけ実行。棚は安全なブックマークを使い元ファイルを複製しません。 |
| メモ・メール・音声 | AppleScript/JXA と自動化権限。音声は実行時だけ録音し、整形テキストは選んだモデルや Provider、CLI のみに送ります。 |
| ブラウザとメディア | 公開ファイル進行、MediaRemote、Core Audio 状態。閲覧履歴を読みません。波形とミキサーはローカル処理、録画は有効にした音声源だけ保存します。 |
| ネットワーク | 天気、公開 IP、更新ミラー選択、ダウンロード、残量確認、依存ツールや CLI 導入。任意の翻訳・音声整形・録画 AI 編集は選んだサービスを使用。Apple 音声認識は言語・環境によって接続します。 |

### 機能別の権限

初回に許可します。拒否後はシステム設定のプライバシーとセキュリティから zisla を許可できます。名称は OS によって異なります。

| 権限・設定 | 必要な場面 | 範囲 |
| --- | --- | --- |
| デバイス制御とデータアクセス（OS によりアクセシビリティ） | 音声を現在の入力欄へ挿入 | パスワード以外の入力欄を見つけ、API または `Cmd+V` で挿入します。未許可でもクリップボードへコピーします。 |
| マイク | 音声入力またはスタジオのマイク | 録音や有効なモニターのため選んだ入力を使います。 |
| 音声認識 | 録音の文字起こし | 入力した音声だけ。音声入力はマイクと音声認識の両方が必要です。 |
| フルディスクアクセス | Mail.app 未起動時のメール | `~/Library/Mail` のローカル索引からアカウント、送信者、件名、要約、日時、既読を読みます。 |
| 自動化 | メール読み書き・返信・既読・削除、Apple メモ読み書き | 対応するシステムアプリの操作。Mail とメモは個別に取り消せます。 |
| カレンダー・リマインダー | 予定 | 別々に許可して読み書きします。 |
| 位置情報 | 現在地の天気 | 一回の位置取得で追跡しません。手入力の場所は不要です。 |
| カメラ | ミラー、スタジオプレビュー・録画 | 対応機能が動作中の選択したカメラ。 |
| 入力監視 | キー音、統計、清掃、修飾キー・マウストリガー | 有効機能のイベント。統計はローカル。通常のグローバルキーには不要です。 |
| Bluetooth | システム内の電池 | 接続・ペアリング済み機器の公開電池情報。 |
| 画面とシステム音声収録 | 撮影、プレビュー、録画、波形、アプリミキサー | 選択した画面・音声。録画はローカル保存、ミキサーは macOS 14.4+。 |
| 通知 | ポモドーロ | 終了時に一回の音とローカル通知。 |
| 選択したフォルダー | 受け渡し、入出力、ダウンロード先 | システム選択ダイアログの範囲。フルディスクアクセス不要。 |

許可の取り消しは対応する機能だけに影響します。変更後も使えない場合は終了して再起動します。詳細は [macOS ガイド](mac/README.md#権限とプライバシー) にあります。
