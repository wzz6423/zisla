# zisla for macOS

[English](../../../../mac/README.md) | [简体中文](../../../../mac/README.zh-CN.md) | **繁體中文** | [其他語言](../../README.md)

這是 zisla 的 macOS 實現：滑鼠移到螢幕頂部中央時展開，移開後隱藏。它使用 AppKit `NSPanel`、SwiftUI 和事件驅動服務實現，不創建常駐透明熱區視窗，隱藏時不運行幀循環。

Swift target、Bundle ID、本地資料目錄和 `zislactl` 均使用 zisla 標識。升級時會自動遷移此前版本的本地資料和偏好設定。

支援 macOS 14 及更高版本。macOS 26 使用 Liquid Glass，macOS 14/15 自動回退到系統原生材質。

### 跨模塊能力

- 系統正在播放：MediaRemote 展示封面、標題、進度、滾動歌詞和播放控制；Core Audio 兜底識別實際輸出音訊的應用，暫停、停止和靜音來源不顯示。
- 瀏覽器下載：在首頁、收起態和側翼通知中顯示 Safari、Chrome、Edge、Firefox、Brave、Vivaldi、Opera 與 Arc 的下載來源和進度。系統暫存資料夾中的 `.crdownload` 檔案本身不會觸發下載卡片。
- 語音輸入：支援按鍵切換或按住說話、自定義全局快捷鍵、系統語音識別、本地或遠端模型整理，以及本機錄音歷史。
- 快捷操作：每次複製後彈出小靈動島提示，展示富內容預覽和智能下一步動作 —— 打開連結、在 Finder 中顯示、搜索（可選搜索引擎）、翻譯、計算、從識別的日期新建日程，以及儲存長文本和圖片。瀏覽器下載完成或收到 AirDrop 檔案後，也可用同一快捷鍵打開檔案所在資料夾；這由快捷操作開關控制，與“瀏覽器下載進度”開關獨立。支援識別 URL、檔案路徑、郵箱、電話號碼、帶實時色塊的 CSS 顏色值、算式、日期時間、非系統語言文本、代碼片段、帶字數統計的純文本、帶縮略圖的圖片和檔案引用。觸發方式：操作按鈕、額外預設 Command+N，或自行配置的修飾鍵/滑鼠側鍵；另提供預設關閉的「按住左鍵 + 點右鍵」快速複製手勢、應用黑名單、識別類型開關和輕量提醒模式。
- CLI 與 Skills 管理：在設定中檢測、安裝、更新和解除安裝常用 AI CLI，並管理本機 Skills。
- 桌面寵物：在「設定 → 寵物」中預覽內建和匯入的寵物。「固定寵物」會持續顯示選定的寵物。「隨機輪替」預設每天在當地午夜從所有寵物中抽選一隻，可以在「隨機範圍」中指定候選寵物。將「切換間隔」設為「自訂」後，可設定 1 秒至 99 小時 59 分 59 秒的間隔，初始值為 1 小時。寵物可以放在靈動島左側或右側。在一個螢幕上展開靈動島時，其他螢幕上的寵物會留在原位。
- 更新：當前選擇的 Release 或 Preview 通道會在本次運行中解析一次公網出口國家碼：`CN` 先通過 Sparkle 檢查帶簽名的 Gitee appcast，再回退一次 GitHub；其他國家碼先檢查 GitHub，再回退一次 Gitee；無法獲取國家碼時保留 Gitee 優先。隨後由 Sparkle 自動下載、驗簽、安裝和重啓；切換通道同時影響自動檢查和手動檢查。
- 外觀與交互：設定視窗可跟隨系統、淺色或深色；靈動島支援透明或磨砂表面、固定展開、多顯示器、Spaces 和無劉海外接屏。瀏覽器進入全螢幕後，將指標移到靈動島上，即可在目前的桌面展開。
- 新安裝預設啓用功能模塊；每項功能、收起態狀態、側翼通知、菜單欄指標和更新行為都可在設定中單獨調整，已有安裝保留用戶當前配置。

- 連接多個顯示器時，在「設定 → 通用 → 顯示器模式」分別選擇靈動島模式（攝影機或自訂位置）、劉海模式，或在此螢幕不顯示。單螢幕時隱藏此設定，使用原有全域樣式；重新連接後恢復各螢幕的設定。啟用靈動島的螢幕會同時顯示收合的靈動島。在一個螢幕上展開靈動島、開啟快速操作、錄音或顯示暫時提示時，其他螢幕的靈動島仍然可見。選擇通知顯示器只決定哪個螢幕顯示通知。

### 獨立工具與工作流

- **螢幕錄影工作室：** 從菜單欄或設定打開。錄制螢幕、視窗或區域，可選系統音訊、麥克風和相機。多軌編輯影片、音訊、圖片和文字，調整字幕、縮放、動畫、人像與聲音效果；預覽後匯出影片、GIF、Live Photo 或音訊。部分格式需要 FFmpeg；支援的設備可錄制 HDR。 可將中轉的圖片、影片與音訊匯入素材庫，保留目前專案與時間軸。
- **圖片、音訊與 PDF：** 從設定進入獨立工具。圖片提供 9 項本機操作和批量/ZIP 匯出；音訊提供 27 項操作，包含混音、LUFS 標準化與噪聲處理，需要 FFmpeg 和 ffprobe；PDF 提供 14 項操作，Office 轉換需要 LibreOffice 或 OpenOffice。
- **每日簡報：** 從設定選擇 8 種模板和統計內容，預覽後手動或定時匯出 PNG；缺失的統計不會顯示為實測零值。
- **視窗預覽：** 在 Dock 懸停或 Command+Tab 切換時預覽視窗，點擊卡片激活目標視窗；從設定管理開關與權限。
- **位置便簽與會議：** 按住設定中的便簽快捷鍵並搖動滑鼠，為網頁、視窗或桌面記錄便簽。帶會議連結的日程在開始前 10 分鐘顯示倒計時，可加入會議、新建便簽或關聯已有便簽；便簽在中轉中管理。
- **中轉搖動投放：** 拖動檔案時搖動滑鼠顯示投放入口；從設定獨立開關該手勢。
- **音訊輸出與播放器偏好：** 從媒體區域選擇輸出設備；在設定中選擇優先播放器或自動來源，調整媒體緊湊佈局和環境音停止條件。
- **AI 額度與重置：** 從 AI 監控和設定查看支援賬戶的剩餘額度、採樣時間、重置時間和低額度通知，包括可用的 5h/7d 視窗和 Cursor 美元預算；這與本機 token 用量歷史是不同資料。 Antigravity 的 Gemini 與 Claude/GPT 額度分別監控、展示和提醒。Gemini App 一般對話額度使用同一 Google 帳號的網站 Cookie 查詢；Gemini CLI 單獨監控。

### 快捷操作的鍵盤順序

快捷操作彈窗按當前動作順序分配 `Command+1` 到 `Command+9`，再到 `Command+0`。新配置的額外預設觸發鍵為 `Command+N`，用於首個動作；`Command+Delete` 關閉彈窗。觸發鍵、滑鼠側鍵與動作順序可在設定中調整。升級保留所有顯式儲存的自定義組合、舊 `Command+1` 和清空狀態；只有新配置或未儲存觸發字段時採用 `Command+N`。

### 儲存位置

從設定 → 儲存位置分別選擇下載、截圖、圖片工具、螢幕錄影、PDF、快捷操作和每日簡報的目錄。新配置預設儲存到 `~/Downloads` 下的 `picture`（截圖/圖片）、`video`（螢幕錄影）、`pdf`、`quick` 與 `daily` 子目錄。音訊工具通過匯出對話框選擇檔案或資料夾。中轉檔案保留原檔案引用；暫存截圖與位置便簽的本地狀態在 `~/Library/Application Support/zisla` 中管理，螢幕錄影工程使用螢幕錄影目錄。隨記正文儲存在系統「備忘錄」。

[用戶幫助與逐步指南](https://wzz6423.github.io/zisla/help.html?lang=zh-Hant#help) 提供剪貼簿、截圖／螢幕錄影、中轉、會議、AI、媒體工具、每日簡報、桌面便箋／視窗預覽與播放／混音九組逐步指南，以及短片段示範。

### 截圖快捷鍵與暫存

截圖功能條的“暫存”位於“釘圖”和“複製”之間。它將當前編輯後的圖片存入中轉站，包含標注和已完成的長截圖，不會自動複製到剪貼簿。PNG 圖片和截圖時的原始應用、捕獲時間等元信息儲存在本機 SQLite 資料庫中，重啓應用後仍可查看；“暫存截圖”分類只顯示這些卡片。

“螢光筆”位於“畫筆”之後，拖出半透明高亮區域；左右端線和圓形標記預設保留，可在工具菜單中關閉。“提取”位於“模糊”之後，可用 macOS 主體識別提取主體或背景，也可自由圈選任意區域；連續圈選多處會合併保留，支援全選和清除。提取後未選中的部分透明，可撤銷恢復。截圖圓角預設為 0，可拖動選區頂部的圓角控制點或使用“圓角”滑塊調整，尺寸徽章顯示 `r`；匯出 PNG 四角透明，調回 0 會恢復原始角落像素。

## 快速開始

### 環境

- macOS 14+
- Swift 6 / Xcode 16+（僅 Command Line Tools 也可構建）
- 可選：`yt-dlp`、`ffmpeg`；Office 轉 PDF 另需 LibreOffice 或 OpenOffice

本機已安裝 Homebrew 時：

```bash
brew install yt-dlp ffmpeg
brew install --cask libreoffice
```

### 運行源碼

```bash
swift run zisla
```

應用以菜單欄附件模式啓動。滑鼠移到當前螢幕頂部中央 6 px 區域即可展開；也可從菜單欄圖標選擇“顯示靈動島”。

若要在除錯版中測試每 5 秒輪替一次，請在儲存庫根目錄執行 `ZISLA_DEBUG_PET_ROTATION_SECONDS=5 make run`，接著選取「隨機輪替」並勾選至少兩隻寵物。不帶該變數執行 `make update` 即可恢復已儲存的間隔。

### 構建 `.app`

```bash
Scripts/generate-icon.sh
Scripts/build-app.sh
open "dist/zisla.app"
```

打包自帶的官方 `yt-dlp` Helper：

```bash
Scripts/fetch-yt-dlp.sh
Scripts/build-app.sh
```

`fetch-yt-dlp.sh` 固定版本下載官方 macOS standalone 檔案，並用官方 `SHA2-256SUMS` 校驗後安裝到 `Tools/yt-dlp`。

## AI 工具接入

### 自動檢測

zisla 會讀取各工具公開或穩定的本地會話狀態，只提取判斷任務狀態所需的結構化事件和本地活動元資料，不讀取提示詞或回答正文：

| 環境 | 自動檢測範圍 |
| --- | --- |
| OpenAI / Anthropic | Codex CLI 與 Desktop、Claude Code 及其宿主環境 |
| GitHub / Google / xAI | GitHub Copilot CLI 與 VS Code、Gemini CLI 與 Desktop、Grok CLI |
| 國內與獨立工具 | Pi、Kimi Code、Qwen Code、Qoder、ZCode Desktop 與 CLI、TRAE、OpenCode、Harnext/Harness、WorkBuddy |

檢測到等待審批或等待用戶回答時顯示黃色，工具或命令報錯時顯示紅色，正常運行時顯示綠色；同一時刻按紅色、黃色、綠色的順序聚合。Qwen runtime sidecar 只有在 PID 仍存活時才生效，避免退出後長期誤報。

普通聊天型 Desktop 應用如果不落盤結構化活動事件，系統無法可靠區分“應用已打開但空閒”和“模型正在生成”。這類工具（包括 ChatGPT 等）應使用下面的 `zislactl` hook 接入；zisla 不會用常駐程序冒充運行狀態。

### `zislactl` 本地協議

`zislactl` 將任務狀態和歷史用量寫入 SQLite：

```text
~/Library/Application Support/zisla/ai-state.sqlite
```

用量歷史不會因應用重啓、覆蓋更新或清空任務而刪除；下次啓動會從此資料庫回讀。只有用戶手動刪除應用資料時，歷史才會丟失。

示例：

```bash
swift run zislactl update \
  --id build-42 \
  --provider claude \
  --title "Refactor index" \
  --progress 68 \
  --detail "17/25"

swift run zislactl usage \
  --provider claude \
  --input-tokens 12400 \
  --output-tokens 2100 \
  --model claude-opus-4-8

swift run zislactl finish --id build-42 --detail "Complete"
```

## 瀏覽器下載進度

zisla 使用 macOS 公共檔案進度機制監聽“下載”目錄，並結合臨時檔案擴展名、下載來源擴展屬性和正在運行的瀏覽器解析來源。它不會讀取瀏覽器歷史資料庫，也不會為識別進度發起網路請求；下載進度的完成標記保留約 3 秒。快捷操作復用這套事件來源，僅在傳輸成功且檔案到達最終位置後提供“打開資料夾”；提示時長跟隨快捷操作設定，新的複製或傳輸提示會覆蓋舊提示。

## 下載器

可執行檔案按以下順序解析：

1. `zisla.app/Contents/Helpers/yt-dlp`
2. `/opt/homebrew/bin/yt-dlp`
3. `/usr/local/bin/yt-dlp`
4. `~/.local/bin/yt-dlp`

URL 作為獨立 argv 傳給 `Process`，不經過 shell。運行時強制忽略用戶配置和插件、禁用 `--exec`、限制單個條目，並驗證最終檔案仍位於授權目錄內。

沒有 ffmpeg 時：

- 影片優先下載 AVC/MP4 影片軌和 M4A 音訊軌，再通過系統 AVFoundation 原樣封裝為 MP4；若站點只提供單檔案則直接儲存。
- 音訊優先已有 M4A，否則保留原始音訊格式。
- B 站影片在 yt-dlp 遇到 HTTP 412、格式不可用或本機沒有 yt-dlp 時，改用 B 站只讀接口獲取 DASH 軌並走同一原生封裝流程，不安裝額外工具。

## 隨記

靈動島內的 Markdown 隨記，以系統「備忘錄」App 作為唯一資料源——既能新建，也能查看、編輯、刪除備忘錄里已有的筆記，而不僅限於新增。

- 列表：進入模塊時通過 JXA（`osascript -l JavaScript`）讀取備忘錄中未刪除筆記的標題與修改時間，按最近修改排序；從備忘錄返回時會同步列表，已移入「最近刪除」的筆記不顯示。點選切換當前編輯的筆記，可刷新、新建、右鍵刪除。
- 查看/編輯：選中筆記後用 AppleScript 讀取其 `plaintext`（即 Markdown 原文）載入編輯器；編輯態使用原生 `TextEditor`，停止輸入約 0.8 秒後自動寫回備忘錄（防抖，避免每次按鍵觸發 AppleScript）。新建則在備忘錄中創建一條新筆記並選中。
- 預覽：內置塊級解析器把 Markdown 渲染為 `AttributedString`，支援標題、無序/有序/任務列表、引用、圍欄代碼塊、分隔線，以及粗體、斜體、行內代碼、刪除線和連結等行內格式。
- 存儲格式：筆記正文按 Markdown 原文存入備忘錄 `body` 的普通文本段落（HTML 轉義並保留空行），讀取 `plaintext` 時還原 Markdown 源文本，由隨記模塊負責渲染。備忘錄 App 內顯示的是普通文本（不渲染），這是用備忘錄做 Markdown 存儲後端的取捨。
- 權限：首次讀取/寫入時 macOS 彈出自動化授權彈窗，允許 zisla 控制「備忘錄」；被拒絕後列表與編輯會返回失敗提示。

隨記不在本地另存一份——備忘錄即存儲後端，避免雙份資料與同步問題。

## 權限和隱私

- 日程：首次打開日程模塊時分別請求日曆和提醒事項權限；新增事件/提醒、刪除或標記提醒完成後自動刷新。
- 定位：天氣預設使用一次性當前位置請求，不持續跟蹤；也可在設定中搜索、儲存和刪除其他地區，同時查看多個地點。
- 檔案和下載目錄：使用用戶選擇目錄的安全書簽；檔案中轉不複製原檔案。
- 剪貼簿：新安裝預設開啓歷史與連結檢測；兩項可獨立關閉。開啓後只在 `changeCount` 變化時讀取一次，最多處理一個連結，不儲存 query 參數日誌，也不呼叫清空、聲明類型或寫入 API，因此不會替換 Mac、iPhone、iPad 之間的通用剪貼簿內容。
- 快捷操作：開啓後在每次 `changeCount` 變化時本地處理，也處理已完成的瀏覽器下載和收到的 AirDrop 檔案，不聯網。單獨修飾鍵和滑鼠側鍵觸發可能需要輸入監控權限；可選的快速複製手勢還會模擬 ⌘C，需要輔助功能權限。打開連結、搜索、翻譯和儲存僅在用戶明確點擊或按下觸發鍵後發生；應用黑名單與識別類型開關控制複製內容提示，快捷操作總開關同時控制傳輸完成提示。
- AI 狀態：自動檢測只讀取判斷任務狀態所需的結構化事件和本地活動元資料。
- 語音：僅在用戶主動觸發時訪問麥克風和系統語音識別；錄音、原始轉寫和 AI 整理文本由用戶在本機管理。啓用模型整理後，轉寫文本只發送給用戶選定的本地模型、遠端 Provider 或 CLI 檔案；遠端 Provider 與 CLI 憑據存入私有資料庫，不寫入普通設定。
- 藍牙與設備：僅在開啟系統中的電池檢視時讀取 macOS 可提供的配件電量和已與本機建立信任關係的 Apple 移動設備電量。
- 相機與輸入監控：鏡子和螢幕錄影工作室的相機預覽/錄制會請求相機權限。鍵盤聲音、按鍵統計、鍵盤清潔與修飾鍵/滑鼠側鍵觸發需要輸入監控；統計儲存在本機，開關相互獨立。
- 螢幕與系統音訊：截圖、螢幕錄影和視窗預覽需要螢幕錄制權限。螢幕錄影在本機儲存所選源，僅為啓用的麥克風/相機請求對應權限。應用混音需要 macOS 14.4+ 和系統音訊錄制權限，使用本機 Core Audio tap。
- 瀏覽器下載：只訂閱系統公開的檔案進度並檢查下載臨時檔案，不讀取瀏覽歷史或頁面內容。
- 媒體：通過 MediaRemote 獲取系統元資料，並用 Core Audio 的程序輸出狀態確認是否正在播放。MediaRemote 是非公開框架，因此當前構建不適合直接提交 Mac App Store；無元資料時降級顯示實際出聲的來源應用。
- 網路：天氣預報按地區查詢中國天氣網、Open-Meteo 和 MET Norway，並在資訊不全時補充查詢；官方天氣預警繼續獨立查詢中國天氣網或 WeatherKit。 更新檢查會在每次程序運行中通過 `ipinfo.io/country` 查詢一次公網出口國家碼：`CN` 使用 Gitee 再回退 GitHub，其他國家碼使用 GitHub 再回退 Gitee，無法獲取國家碼時保留 Gitee 優先；B 站備用下載訪問其只讀影片信息、播放地址和媒體 CDN；識別剪貼簿連結本身不聯網。啓用的 AI 賬戶額度檢查訪問所選 Provider；可選翻譯、螢幕錄影 AI 編輯與轉寫整理訪問所選模型或 CLI。系統語音識別是否訪問 Apple 服務取決於語言與系統支援。依賴組件和 CLI 安裝更新、公網 IP 查詢，以及用戶明確選擇的網路動作也會發起請求。
- 自動化：隨記通過 AppleScript/JXA 讀寫系統「備忘錄」App 中的筆記（列出、查看、編輯、新建、刪除），首次使用需在彈窗中授權 zisla 控制「備忘錄」；隨記不聯網，筆記資料存在備忘錄中。

## 系統限制

- macOS 沒有公開的“靈動島”API；物理劉海通過 `safeAreaInsets` 和頂部輔助區域推斷，無劉海螢幕使用同樣的自有覆蓋層模擬。
- DRM 影片、登錄視窗、鎖屏和部分獨佔全屏應用不保證提供 Now Playing 資料或允許覆蓋層顯示。
- 未接入系統媒體中心的應用仍可識別正在輸出音訊的來源，但無法保證提供曲名、封面或進度；暫停、停止和靜音影片按設計不顯示。
- 瀏覽器必須向 macOS 發佈檔案進度，或在“下載”目錄使用可識別的臨時檔案，zisla 才能顯示下載百分比。
- 電池健康、溫度、實時功率和配件電量取決於硬件、連接方式及 macOS 實際暴露的資料；缺失字段會顯示為不可用。
- Office 轉 PDF 依賴本機 LibreOffice 或 OpenOffice，其餘 PDF 操作在本機直接完成。
- 發佈包未經公證，首次打開可能需要在系統設定中選擇“仍要打開”。正式版使用同一張自簽名證書，使 macOS 權限授予能在後續更新中保留；Sparkle 仍會獨立使用應用內置 EdDSA 公鑰驗證每次更新，再解壓、替換並重啓應用。
