# zisla 官网

[English](README.md) | **简体中文**

这是仓库根目录下的 TypeScript 官网，使用 Vite 构建，页面文案和下载入口与仓库当前 macOS Release 保持一致。官网展示 12 个灵动岛模块，以及每日简报、上下文关怀和便签、自定义宠物、录屏工作室、截图识别与翻译、Cursor 和 Muse Code 监控、应用音量混音器、PDF 工具与集中权限等能力，并补充录屏人像与美声效果、自选颜色的平滑光标轨迹、手写附件预览、独立保存位置、定时系统垃圾清理、剪贴板历史自动删除和 Quiet.md 推荐；文案覆盖全部 17 种语言，更新日志与 v0.1.22（2026-11-07）一致，系统历史默认保留至手动清空。

## 本地运行

```bash
cd web
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
