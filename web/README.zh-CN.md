# zisla 官网

[English](README.md) | **简体中文**

这是仓库的 TypeScript 官网，使用 Vite 构建，页面文案和下载入口与当前 macOS Release 保持一致。官网展示 12 个灵动岛模块与 19 项独立能力，包括 9 项图片工具、27 项音频操作、PDF 工具、AI 额度环与模型用量历史、会议倒计时与关联便签、中转站批量操作、自动电源模式、紧凑番茄钟、HDR 与自动滚动截图、应用打开修复和每日简报；同时涵盖录屏人像与美声效果、独立保存目录、定时清理、设置重组、依赖组件每日更新、浏览器真实下载文件名和 Zshell 推荐。160 秒功能导览由用户点击后播放。文案覆盖全部 17 种语言，更新日志与 v0.1.23（2026-11-14）一致，系统历史默认保留至手动清空。

## 本地运行

```bash
cd web
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
