# zisla website

**English** | [简体中文](README.zh-CN.md)

This directory contains the repository's TypeScript website, built with Vite. Page copy and download links match the current macOS Release. The site presents 12 island modules and 19 standalone capabilities, including nine image tools, 27 audio operations, PDF tools, AI quota rings and model usage history, meeting countdowns and linked notes, shelf batch actions, automatic power modes, compact Pomodoro controls, HDR and scrolling screenshots, application-opening repair, and daily briefings. It also covers recording portrait and voice effects, independent save folders, scheduled cleanup, reorganized settings, daily dependency updates, actual browser download filenames, and the Zshell recommendation. A 160-second feature tour plays on request. Copy covers all 17 languages, and the changelog matches v0.1.23 (2026-11-14). System history is retained until manually cleared by default.

## Run locally

```bash
cd web
npm install
npm run dev
```

Production build:

```bash
npm run build
```
