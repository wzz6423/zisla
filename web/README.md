# zisla website

**English** | [简体中文](README.zh-CN.md)

This directory contains the repository's TypeScript website, built with Vite. Page copy and download links match the current macOS Release. The site presents 12 island modules, daily briefings, contextual care and notes, custom pets, a recording studio, screenshot recognition and translation, Cursor and Muse Code monitoring, an application volume mixer, PDF tools, and centralized permissions. It also covers recording portrait and voice effects, smooth cursor trails with custom colors, handwritten attachment previews, separate save locations, scheduled system cleanup, automatic clipboard history deletion, and the Quiet.md recommendation. Copy covers all 17 languages, and the changelog matches v0.1.22 (2026-11-07). System history is retained until manually cleared by default.

## Run locally

```bash
cd web
npm install
npm run dev
```

Production build:

```bash
npm run build
```
