# 风险驱动测试矩阵

在主技能识别风险后，使用本矩阵把风险转换为可执行 case。每一行都要验证可观察的契约、失败后的状态和清理，而非只测实现细节。只实现与改动相关的行；不适用时在交付报告说明原因。

| 层级 | 适用信号 | 必须覆盖的性质 | 隔离和稳定性 |
| --- | --- | --- | --- |
| 单元 | 纯模型、转换、规则、解析 | 正常、空值、边界、无效值、幂等/不变式 | 固定时钟、随机 seed 和 locale；不用真实磁盘或网络 |
| 集成 | 多模块、SQLite、文件、CLI、编码/解码 | 写读往返、事务失败、重启后状态、错误映射 | 每个 case 独立临时目录/数据库；断言文件权限和清理 |
| 系统契约 | 框架适配、子进程、权限、通知、下载 | 请求条件、拒绝/取消、不可用、恢复、无副作用 | 经 protocol、fake 或 loopback seam；不调用真实账号或系统设置 |
| Smoke | 启动、关键命令、构建、包结构 | 可构建、核心路径最小输入、退出码、关键资源存在 | 快速、离线、无 UI 观察依赖；单次失败可诊断 |
| 回归 | 已修复缺陷、兼容承诺 | 旧复现步骤触发前会失败、修复后稳定通过 | 用最小 fixture 和明确的行为名；不要只复制生产实现 |
| 安全 | 外部输入、隐私、权限、持久化、执行边界 | 拒绝注入/越权、无敏感输出、最小权限、失败无副作用 | 假凭据和 mock；不要把漏洞 payload 发往真实服务 |
| Fuzz/属性 | 解析器、协议、迁移、CLI、序列化 | 不崩溃、不会越界写入、失败可预测、往返/单调等性质 | 固定 seed、输入/时间预算、保存最小失败语料；默认短跑 |
| Chaos | 重试、并发、取消、外部服务、部分写入 | 超时、断连、重复/乱序、磁盘/权限失败后的一致性、可恢复性 | 仅故障注入；不真实断网、杀进程或填满磁盘；非默认门禁 |
| 性能/资源 | 热循环、大输入、后台任务、生命周期 | 有界时间/内存/句柄、取消生效、无重复任务或泄漏 | 记录环境和基线；避免将波动指标设硬阈值 |
| 升级兼容 | schema、设置、序列化格式、CLI/公开 API | 旧数据可读、迁移原子性、失败回滚、默认值、明确降级策略 | 固化真实旧版本 fixture；迁移目录必须可清理 |

## 安全 case 检查项

根据接口类型挑选攻击输入并断言行为：

- 文件/URL：`..`、绝对路径、编码绕过、符号链接、重定向、非预期 scheme、超大和截断内容。
- 文本/HTML/Markdown/SQL/命令：转义和编码边界、控制字符、嵌入标签/查询/命令片段；断言不执行、不泄漏、不会改变范围外的数据。
- 凭据/隐私：日志、错误、缓存、迁移和导出中不出现假凭据明文；失败不会创建过宽权限的文件或旁路用户开关。
- 并发/持久化：同时读取和写入、取消、中途错误、重复提交、WAL/临时文件遗留；断言最终状态一致并可重新打开。

## case 质量门槛

- 每个 case 只围绕一个行为命名，例如 `testRejectsTraversalWithoutCreatingOutput`，并为失败提供可读信息。
- 对 bug 修复保留最小失败输入；对 fuzz 失败将 seed 和最小语料转成普通回归 case。
- 对异步行为使用可控时钟、事件或 expectation，不用任意时长 `sleep`。
- 对测试双替身验证协议契约；不要仅因 mock 返回了期望值就宣称系统集成通过。
- 当某类测试过慢或偶发时，先消除共享状态、时间依赖和非确定输入；仍不能稳定时移至显式 opt-in，不能隐藏为通过。
