# 开发者真实体验验收单

AI 在编码前根据变更选择以下项目，并在交付中原样列为“待开发者亲验”。开发者在目标环境完成后提供实际结果；AI 不得代填“通过”。

## 基础体验

- [ ] 从干净启动状态启动应用，观察首屏、菜单栏和关键入口是否可用。
- [ ] 按真实用户路径执行新增或变更功能：操作、预期可见结果、失败提示和返回路径。
- [ ] 使用鼠标、键盘、触控板和全键盘导航检查焦点、快捷键、撤销/取消和无障碍标签（与本次变更相关时）。
- [ ] 在实际屏幕尺寸、缩放、深浅色和本地化语言下检查布局、截断、层级和动画/过渡（与本次变更相关时）。

## macOS 系统边界

- [ ] 在真实权限状态下验证首次请求、拒绝、稍后授予和撤销后的行为；不把模拟授权当作此项通过。
- [ ] 在外接显示器、无刘海屏、锁屏/唤醒、前后台切换、休眠恢复和多空间场景下验证窗口、浮层和生命周期（与本次变更相关时）。
- [ ] 使用真实输入设备、剪贴板、文件选择器、拖放、媒体播放或辅助功能权限验证交互（与本次变更相关时）。
- [ ] 在可控的实际网络和账户状态下验证用户可见的加载、取消、错误、重试和隐私提示（与本次变更相关时）。

## 数据与升级

- [ ] 在真实或已备份的代表性本地数据上验证升级后的读取、写入、关闭重开和失败恢复；确认不丢失、不重复且无意外迁移。
- [ ] 检查设置开关、默认值、历史行为和回滚路径；确认未改变未涉及功能。

## 记录格式

为每项保留最小证据：环境（macOS/硬件/版本）、步骤、预期、实际、通过/失败、已知限制。任何未做项保持“待开发者亲验”，而不是“无需测试”。
