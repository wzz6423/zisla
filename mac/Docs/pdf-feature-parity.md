# 本地 PDF 功能对齐清单

本文件以 Stirling-PDF 主分支 `app/core/src/main/java/stirling/software/SPDF/controller/api/` 的公开工具控制器为盘点来源。只参考功能范围，不复制其实现、接口或前端代码；zisla 的所有处理在本机完成，不调用 Stirling-PDF API。

## 范围

- 纳入：面向用户的 PDF 处理、转换、OCR、编辑、安全和自动化工具。
- 不纳入本地 PDF 引擎：账号、团队、SSO、计费、审计、远程 REST API、服务器配置。这些是多租户服务能力，不是桌面文档处理能力。
- 状态：`已实现` 表示已有可调用本地服务；`计划` 表示必须实现，未完成前不得在 UI 中宣传。

## 验收规则

1. 每个工具必须有独立服务层、单元测试和从文件中转入口到输出文件的集成测试。
2. 涉及视觉输出的工具必须用渲染后的页面图像检查，不仅验证文件存在或页数正确。
3. 处理过程中只允许访问用户授权的输入、输出和临时目录；不得上传文档。
4. 真脱敏、签名、PDF/A、Office 反向转换等高风险功能必须以内容验证作为验收条件，不能以表面显示或扩展名替代。
